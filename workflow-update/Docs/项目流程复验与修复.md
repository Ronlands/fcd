## 实际发现并修复的问题

| 问题 | 修复后的行为 | 验证 |
| --- | --- | --- |
| 项目中其他裁片自交时，合格单片的预览、PDF 与打印也被阻止 | 前端与主进程都按本次输出的裁片范围检查。只打印合格单片可以正常输出；勾选含坏片的批次仍拒绝。所选裁片与未打印裁片的接缝仍按完整项目检查，所选花纹保留原始依赖失效检查 | 实际创建合格矩形与自交裁片；单片导出为一页 PDF，包含坏片的请求返回 `INVALID_GEOMETRY`；选择接缝 B 侧且 A 侧未打印时，错误长度仍返回 `INVALID_SEAMS`；修改来源后单片预览拒绝过期推断花纹 |
| 警告确认在编辑之后继续有效 | 当前单片、批量范围或项目版本改变后须重新审阅。总导出与展开候选的确认也随项目版本失效 | 修改裁片名称后不能沿用旧确认；导出窗口保持打开时，通过真实本机助手修改项目，原确认清空，重新确认后才可输出 |

| 并发开启本机助手时，各次启动互相撤销，出现 `ASSISTANT_DISABLED` | 同时开启共用一次启动和同一令牌；关闭仍撤销旧授权，重新开启建立新连接 | 8 个并行开启请求返回同一地址和令牌；关闭正在启动的连接后，旧请求失败，新连接正常 |
| 可写副本执行 `npm run test:rust` 找不到 Cargo | 检查当前目录及父目录的已有 Rust 工具链和离线依赖 | 标准 npm 命令运行 6 项 Rust 测试通过 |

原有测试中还有页面导航、按钮名称和毫米字段的旧假设。已更新脚本以操作现在的五个独立页面，保留原来的几何、颜色、投影、撤销、重启和导出断言。导航会等待当前提交完成，避免展开采用后的自动跳转与下一次点击冲突。`npm run test:desktop` 默认覆盖全部 21 套验收。

## 完整流程复验

1. 上传合并双视图，自动拆成正背花纹并保存至独立分类库；实际 JPEG 双视图完成双侧标定、RGB/Lab/HSV 分割、蒙版编辑与撤销。
2. 生成或上传模型，自动保存，改名/选择/删除可操作；花纹抽屉缩放、贴附和补画保持模型关联。既有二维来源也能贴附。
3. 模型上的点选切线、曲面钢笔、自由绘制、对称、截面、插点、线组继续绘制和半侧中线设置产生实际切缝。展开候选经审阅采用后，生成颜色一致的独立裁片；外边界、孔洞和反向定位仍可编辑。
4. 单片与全选输出按毫米原尺寸分页；A3/A4 拼接、区域切换、第 2/5 页补印、100 mm 尺和物理页尺寸已验证。ZIP 保留可编辑裁片、标签、颜色、模型及花纹，导入与重启可以恢复。
5. 制作节点可查看、编辑并进入对应编辑器；JSON 往返保留项目数据和节点记录。本机助手的版本检查、重试幂等、权限范围及关闭恢复已验证。

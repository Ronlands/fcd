# 离线 0.7：大模型、颜色分割与曲线候选

本记录对应 0.7.0 增量。父需求仍为部分实现，不能据此宣布完整设计全部验收。AI、云服务、账号授权及签名发行按用户要求暂缓。

## 操作与已实现行为

- 左侧 3D、右侧二维裁版：旋转、平移、缩放、复位；预览与参数区之间的分隔条可以拖动或用上下方向键调整。显示调整不增加项目版本。
- 导入 OBJ / 静态 GLB：最多 20 万顶点、20 万面，文件最多 64 MB。超过 5000 面采用 Canvas；默认显示 LOD 目标 12000 面，并显示原始数量和最大顶点位移上界。LOD 只用于显示；制造、绑定和点击拾取使用原始网格。无法安全合并的独立小部件保留完整网格。
- 开启完整细节、区域选择、花纹或失真热图会使用完整网格，速度可能下降。材质颜色预览读取裁片颜色，不是布料物理模拟。
- 展开最多 5 万面，LSCM / ARAP 保留原始面；自动切缝采用增量拓扑检查。展开和花纹投影在后台执行，最长 120 秒，可取消；失败、超限或取消保留原项目及已接受纸样。超过 5 万面明确拒绝，不自动简化制造数据。
- 一个 3D 面对应多张纸样时同时高亮候选，由用户选定后映射准确位置。过期绑定不参与拾取。
- 每面热图可切换 D、面积 EA、边长 EE、角度 Eθ。固定显示尺度分别为 0.05、0.15、0.10、0.05；缺失值为灰色。角度尺度仅用于显示，不是材料或制造合格阈值。
- 参考图分割新增 Lab / HSV 全局颜色聚类：点击一种颜色，保留所有同色连通区域；颜色数 2–16，最小区域 4–1000 像素。5 位 RGB 直方图、最多 20 次确定性迭代；透明像素排除，小区域丢弃数量明确报告。原有 RGB 泛洪与手工 mask 继续可用。
- 曲线拟合可选 0.01–0.5 mm 公差。只拟合候选外环，孔保留原多边形。报告双向 Hausdorff 距离保守上界、节点减少量及回退数；超差、资源超限或无收益保留原轮廓。原已接受纸样不会被自动覆盖，接受前仍经过原生制造校验。
- 颜色聚类及拟合参数、结果随接受后的源 mask 和项目包保存，可撤销、保存与重启回读。旧项目不要求具有这些可选字段；新算法数据需新版软件读取。

Lab 数学转换采用 sRGB → XYZ D65 → Bradford D50 → CIELab，参考 [W3C CSS Color 4 转换代码](https://www.w3.org/TR/css-color-4/#color-conversion-code)。这些是传统图像算法，不提供语义识别或侧面推测。

## 资源与一致性

项目包解压总预算 200 MB；进程消息与几何工作进程输入预算 64 MB。GLB 使用大网格 32 位索引，并在解码前校验 accessor 数量与累计计数。取消会清理所属几何子进程。近期项目列表仅查询摘要，避免反复解析大型快照。

跨片花纹以空间树做宽阶段筛选，保留精确遮挡、裁剪和 UV 映射；原生裁剪分批执行，不绕过原有单请求预算。超限会报错，不丢弃剩余面后冒充完整结果。

## 验证证据

证据目录为 [evidence/0.7.0](evidence/0.7.0)。verification.json 记录类型检查、单元测试、Rust 测试、格式、Clippy 与构建结果；final-validation.json 汇总便携程序桌面回归；source-manifest.json 记录实际源码哈希。

合成直筒曲面：半径 200 mm、高 1000 mm、5 万面，ARAP 展开成 4 张各 12500 面裁片，全部面保留，面积误差小于 0.1%。1 次冷启动、3 次预热、20 次测量的报告哈希一致；中位数 2438.579 ms、P95 2486.786 ms、最大 2492.530 ms。平台为 Windows 10.0.26200、Ryzen 7 9800X3D、32 GB、Node 24.21；父进程观察峰值约 656 MB，未测原生子进程 RSS。详见 cylinder-50000-benchmark.json。

20 万面导入、保存与 LOD 桌面回归已执行；Canvas 绘制采样只代表绘制函数耗时，不代表整个应用帧率。5 万面跨片花纹测试核验完整面数和面积。桌面自动回归因本工具运行环境限制使用测试专用 --no-sandbox；正式应用仍使用 sandbox:true，默认系统沙箱尚需真实用户桌面验证。

## 仍未完成与验收边界

- 文档要求的 2048 纹理 GPU / 20 万面完整场景帧率、100 片复杂曲线场景、200 MB 项目性能、20 次关闭的完整内存基准尚未全部执行。当前显示为 Canvas，没有 GPU 材质纹理渲染。
- 参考图输入仍限原文件 4 MB、解码 400 万像素，分割代理长边 512 px；两张 4096 图像和 Original/Proxy/Thumbnail 完整资源链尚未实现。
- 任意三维花纹曲线编辑、GLB 纹理按已有 UV 转为制造花纹、语义分割和侧面补全尚未实现；当前可用流程是参考图区域投影到真实 3D 面，再沿展开绑定裁剪跨片花纹。
- 真实打印、材料弹性试样、缝制、试穿与工艺验收尚未完成；合成直筒验证不能替代人体和动物复杂网格的全面验证。
- 正常 Windows 系统沙箱及 macOS / Linux 发行未验收；云端服务、AI、商业授权、代码签名需要外部条件。未来 SDK、布料物理模拟等仍未实现。

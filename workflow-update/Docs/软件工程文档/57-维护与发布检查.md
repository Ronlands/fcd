## 发布阻碍与边界

1. 当前受限主机上，正常沙箱启动发生渲染/GPU 子进程 `-1073741515` 失败。使用原始 Electron、只有一页静态 HTML 的最小程序也复现；因此不能宣称正常 Windows 环境的生产启动已经验收。完整日志摘要保留在最终审计中。
2. 根目录旧 `package.json` 的修改被文件权限拒绝，根目录 `npm start` 仍指向旧版。使用 `启动新版FurryCAD.cmd` 或在维护目录运行 `npm start`。
3. 当前包未签名，仍是开发预览；签名证书、安装/升级/卸载验证以及普通 Windows 环境验收尚未完成。未执行外部发布。
4. 实际打印机 1:1 尺寸、材料裁切和缝制试作仍需实物验收，不能以 PDF/SVG 数值测试替代。
5. 花纹部位分类仍是启发式建议；阴影、同色角/耳边界和不可见区域仍需人工复核。自动补全不是对真实遮挡形状的保证，算法范围详见第 56 号文档。

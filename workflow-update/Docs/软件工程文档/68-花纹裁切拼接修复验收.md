当前发布包：`FurryPatternCAD-0.8.0-win-x64-36582631`，构建 SHA-256：`36582631a3eb98ce367f7b44b5b2690b631382a0a696d390dff64216ca06654f`。启动父目录的“启动新版FurryCAD.cmd”会读取此最新版。源码已集成到当前维护目录；Git 提交、合并受只读权限阻止，未伪称完成。

## 六项需求

| 需求 | 实现及验收 |
|---|---|
| 花纹边缘 | 从原始分辨率恢复数字直线和受像素约束的曲线；相邻颜色共用边界，保护尖角与孔洞，不做外观圆滑。真实菱形保持直边，增加斜率、接触边、闭环和三色交点回归。 |
| 贴到模型 | 修复复杂轮廓预算、部位定位和抬手朝向；补识别无粉色肉垫的白手、黑爪，并按前臂至手部的方向整体贴附。实际 JPEG 两个目标白手及四爪保留约 98%–102% 的缩放像素面积；未改动蓝白图原有 152 个变换。 |
| 按花纹和裁切线裁版 | 初始区域由可见材料边界及用户切线形成；仅为拓扑展开、实际畸变和制造有效性添加接缝。微小有效色块保留，颜色、孔洞和全模型面积均核验。 |
| 拖动卡顿 | 路径缓存、帧内合并交互更新、一次手势一个撤销事务；267 片和复杂轮廓拖动回归通过。 |
| 独立拼接页 | 在制版之前加入“拼接预览”；从真实裁片三维绑定重建，缺片/过期绑定显式显示缺口或拒绝预览，支持旋转、分解及逐片检查。 |
| 全选总览 | 屏幕排布与实际尺寸打印分页分开，全部裁片自适应铺入总览；267 片以及两张真实图片的全部裁片都验证数量、边界及可见范围。 |

同时回归重复更换双视图、编辑 Ctrl+Z/重做、模型花纹尺寸、画笔与截面裁切、模型/提供商设置、项目保存恢复及导出等既有功能。总览弹窗打开时不允许快捷键修改背后项目，关闭后撤销恢复正常。

## 最终发布包结果

- 单元/集成：148 文件、755 项全部通过；原生 Rust 30 项通过；TypeScript 通过。
- 隐藏桌面回归：64 个套件全部通过，报告均指向上方同一发布包。
- 原 JPEG：102 个源区域、78 个贴附，最终 301 片。
- 蓝白 PNG：133 个源区域、152 个贴附，最终 482 片。
- 两张图都完成公开接口导入、贴附、裁切、接受、撤销/重做、项目和 ZIP/SVG 导出、重开、100% 面积拼接及全部裁片总览，共各 9 项完整流程检查；制造错误为 0。独立裁后颜色审计：JPEG 无错色；蓝白图有一处 0.0000044651 mm² 的数值边界容差差异，无实质错色，逐项数据见附件 JSON。
- 每片保留硬限制：面积误差不超过 15%、边长不超过 10%、综合畸变不超过 15%；JPEG 63 片、蓝白 100 片仍标记为需要复核。

隐藏窗口拖动调度测量（16 ms 测试调度器，不等同 GPU FPS）：

- 267 cut pan：p95 18.1 ms
- Dense piece pan：p95 32.3 ms
- Dense piece translate：p95 22.3 ms，提交 245.7 ms

完整 8,534 面无颜色整模测试也通过：诊断时生成 133 片，裁切约 220 秒；默认 design 采用有界 600 秒完整任务时限，取消、子进程清理、原子提交及几何限制仍保留。旧 mesh 无色裁切和普通投影仍为 120 秒。

## 使用范围与限制

识别几何相对已分类像素掩膜有 1.05 原生像素误差上界；抗锯齿、阴影、遮挡和语义歧义仍需人工核对。自动贴附不能凭双视图保证未知侧面、隐藏表面或袖口范围完全正确；可在模型上继续调整。拼接页还原实际裁片保存位置，不模拟布料张力、缝合变形或保证实物合身。

原生格式化和 Clippy 检查受环境祖先配置访问拒绝（OS error 5）阻止；构建、原生测试和完整功能测试已完成，未把这两项记为通过。

# 花纹映射可用性修复

日期：2026-10-08。维护目录：`D:\Codex\furrycad\workflow-update`。

## 已复现的问题与修复

- 花纹库卡片没有拖放实现。增加来源拖放事件，只接收当前项目的有效花纹 ID，落点必须命中可见模型。先生成独立草稿，支持平移、缩放、旋转和外轮廓节点调整，确认后计算并保存；保留孔洞和曲线展开后的轮廓。空白处放下、取消和无效输入不修改项目。
- 三维手绘只记录按下时的一个点。增加自由手绘运动采样与节点拖动，保留折线和闭合样条；限制节点数量，拦截自交、重合点和零面积选区。绘制期间锁定相机，项目/模型切换清除草稿，计算期间禁止继续编辑。
- 模板耳朵的细长投影三角面触发 `PROJECTION_NUMERICAL`。复现坐标为 `(98.6142, 1763.3118)`，旧重心权重为 `(0.573253125, -0.003615147, 0.430362022)`。裁剪的 0.0001 mm 网格舍入被细长三角面放大。改为检查实际几何距离，只允许 0.0002 mm 内的点投影到最近边；超限仍拒绝。统一用于正向投影和片内逆映射，规范化负零，保证保存往返一致。
- 自动批量贴附遇到单个无效轮廓或重叠面时整体终止。现在明确列出该区域的失败原因，保留可用结果；取消、资源限制及未知计算错误仍不提交半批结果。
- 自动贴附报告在状态刷新时被错误清空。改为比较实际项目、模型及来源 ID，报告正确保留。单个来源匹配失败也显示原因，不再无提示返回。
- SVG 与 Canvas 统一不透明模型面和花纹填充，消除背面颜色透到正面的误导。
- 补充无效轮廓、投影精度的中文提示和使用指南。

## 结果与边界

实际旧项目为 114 个来源、3624 个模型面。自动贴附成功 63 个，51 个因左右分类缺失、比例失衡或没有合格可见投影而跳过，并显示原因。不能把跳过区域算作已修复完成的自动匹配；这些区域需要分类修正或拖放调整。自动位置仍须检查确认后才能制造输出。

本次只在隔离副本进行项目操作，没有覆盖用户原始数据库。拖放为独立副本，后续修改原花纹不会自动改变该副本。新增可选孔洞字段需要使用本次新版打开。

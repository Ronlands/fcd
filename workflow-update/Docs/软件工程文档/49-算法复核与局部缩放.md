# 算法复核、套索选区与局部缩放

更新日期：2026-10-07。依据用户异常花纹及画笔截图修复，五页职责仍采用现有独立页面。最终验证范围与运行文件哈希见 [本轮汇总](../../test-results/reference-workspace-verification.json)，实际交互断言见 [选区与缩放验证](../../test-results/reference-workspace.json)。

## 异常来源与修复

近白抗锯齿像素没有被原来的背景条件包含，形成一圈独立细条；高级自动拆分只去除主背景颜色类，其他相近的边缘颜色还会成为区域。另外，点击图片两侧留白时，原坐标函数把外部点夹到图片边缘，画笔或种子点击可能在边缘留下细条。上述问题均先通过失败用例复现，再修改实现。

简单与高级自动拆分复用 `packages/reference/background.ts`：统计不透明边框的主色，可靠时从边框向内移除相近颜色及透明背景。只沿四邻域连通背景清理，不把所有白色都删除；被角色边界包围的白毛、明显深色花纹、窄的对比色条保留。背景与毛色相近且没有分界时，图像本身无法可靠区分，使用套索补选并复核。

简单模式继续按基础毛色合并明暗色、抑制描边碎片，使用 `packages/reference/smooth-contour.ts` 的受限曲线简化像素阶梯。高级像素 mask 保留逐像素轮廓，便于精确修正。所有生成区域在提交前通过同一几何服务验证；失败、超限、取消或旧修订不能留下半批花纹，也不能直接成为制造产物。

已经保存的来源不会静默改写。旧项目中的异常拆分需在简单模式点击“按当前标定重新拆分”，检查结果后再贴附；存在来源锁定时先按界面提示处理。重新拆分会使依赖旧来源的贴附失效，避免沿用错误位置。

## 套索与画笔

手工 mask 默认选择“套索选区（替换）”。按住左键圈出区域，松开即闭合并选择内部；半透明着色及虚线表示已选区域。用“套索增加选区”“套索减去选区”组合选区；减去内部区域保留孔洞。单次完成手势对应一次撤销，Ctrl+Z/Ctrl+Shift+Z 在 mask 工作区只操作选区草稿。

画笔加画、擦除继续用于连接带及局部细修；半径单位是处理栅格的像素，不是 mm，也不会随显示放大变粗。处理栅格长边最多 512 px，缩放查看不会重新采样或改变标定。计算候选时按参考图标定换算到 mm，再复核轮廓。

图片外的留白不能开始绘制或设标点；绘制过程中越界会限制到有效栅格范围。Escape、失去指针捕获、窗口失焦、切工具、忙碌或移除编辑器会取消未完成手势。路径最多 2000 点，超过限制取消本次操作并显示说明。未完成绘制不能计算候选，视图缩放不能中途改变绘制坐标；异步计算还核对图像来源及草稿是否变化。

## 所有图形工作区的局部查看

共享 `ZoomViewport.vue` 和 `packages/ui/viewport.ts` 提供独立相机，按钮缩放、鼠标所在位置滚轮缩放、空格或中键拖动平移、手形工具和适合窗口。键盘 +/− 缩放、0 复位。显示百分比相对于初始适合窗口视图，范围 10%–3200%。

| 工作区 | 查看方式 |
| --- | --- |
| 简单双视图正面、背面 | 分别缩放平移，互不改变相机 |
| 高级标定图片、正背叠加、手工 mask | 三个独立局部相机；放大后标点和选区仍使用图像坐标 |
| 花纹库及共享抽屉 | 缩略图大小滑块；选中来源有独立路径预览及局部相机 |
| 纹理图片 | 同一局部相机，颜色种子与图像坐标保持一致 |
| 排料各材料纸张 | 各纸张独立相机，排料尺寸以 mm 保留 |
| 打印拼接总览与单页预览 | 分别放大细节，预览相机不会改变输出 SVG/PDF 或项目版本 |
| 3D 模型及 2D 裁片编辑 | 保留已有滚轮相机和画布平移，编辑点位仍用模型/毫米坐标 |

五页左右分隔仍由唯一 `WorkspaceSplit.vue` 实现，详见 [左右预览布局](40-左右预览布局.md)。局部相机只改变 SVG viewBox 或既有相机状态，禁止将显示放大当成裁片实物缩放。A3/A4 输出继续使用统一毫米打印计划及 100 mm 校验尺。

# 离线 0.5：手工 mask、自定义 Morph 模板与协调花纹编辑

日期：2026-10-05。对应 REQ-011/012/013/018/020/021 的离线增量，保留 0.4 已通过的制造功能。本记录描述实际能力，不代表完整 MVP、工艺或商业发行验收。

## 手工 mask 与多区域

参考图 → 手工 mask 与多区域 → 放大 mask 编辑。支持连续圆形画笔加画/擦除、多边形增加/移除、填孔、移除点选区域、显式 3×3 平滑。擦除连接带拆分四连通区，加画连接带合并区；所有区域都转为独立候选纸样，孔洞保留。低于 4 像素的小岛、边界歧义、超过 100 区域/轮廓预算等明确拒绝，不能丢弃后冒充成功。

草稿最多 30 次本地撤销/重做；计算候选后进入项目事务历史，接受才增加纸样。计算失败不会修改旧候选/纸样。未计算草稿不随项目保存，界面明确标记。原图/标定发生变化时重置草稿；主进程校验 sourceHash、proxy 尺寸和当前 revision，防止采用旧标定的数据。

代理图长边 512 px，像素边界按原图到代理图比例再经两点标定转为毫米。接受时保存不可变 maskSources：来源 ID、二值像素、分辨率、算法、原图尺寸、标定和输入 SHA256；纸样 sourceMaskId 引用它。以后提取或计算新候选不会覆盖已经编辑的纸样或旧来源。最多 20 个来源，按钮只能清理不被任何纸样引用的来源；仍在用的来源不会删除。独立源区域继续可以投影到全部对应 3D/2D 花纹。

当前所有候选区域采用同一所选颜色，接受后可独立改色/材料。颜色分类、语义识别、自动 Bézier 拟合与 AI 仍非已交付能力。多数滤波可能损失小细节，必须审阅像素数和轮廓，不自动使用。按二值同值连通区填充：点孔内填孔，点外部会填充外部背景。

实现：packages/reference/mask.ts、reference-segmentation.ts、references.ts、MaskEditor.vue、schema/repository/archive。兼容旧单片 referenceRun；新可选 pieces/mask/algorithm 字段保留全量结果。

## 自定义模板与有界 Morph

3D / 展开 → 自定义模板与 Morph 拟合 → 导入 .fpctemplate / JSON。只读取数据，不执行脚本、加载外链或自动下载资源。定义格式含版本、ID、名称、许可文字、mm 网格、Morph 位移及权重上下限、测量环及目标范围/公差。公开 JSON Schema 在 packages/schema/generated/custom-template.schema.json。随包样例 assets/templates/calibration-shell.fpctemplate 是原创校准壳，**不是人体/物种模板或制造验收样品**。

文件限 4 MB，封闭连通且方向一致的三角网格限 3000 顶点/5000 面；最多 16 个 Morph、32 项测量、累计 16000 个位移和 10000 个测量节点引用。测量为明确节点集合的 Y 高度，或沿真实网格边闭合路径的长度。位移使用 mm，权重无量纲，目标使用 mm；不混用同名量。

有界阻尼 Gauss-Newton、有限差分 Jacobian 和下降线搜索最多 40 次/5 秒，所有权重钳制到模板范围。输出实际目标、实测、残差、权重、初末目标函数和迭代次数；达到文件定义公差才提交。未知参数/超范围、无法拟合、退化或相对基础面的翻转会拒绝，保留原身体。相同模板更新保持 ID、拓扑版本和锁定切缝，旧展开/花纹失效，可撤销恢复。项目冻结原始定义、许可备注、SHA256、目标和拟合结果，重新打开不依赖原文件；原始定义可单独导出。

这提供通用**显式 Morph 模板**拟合；未给内置动物模板自动产生任意 Morph，也不自动识别解剖测量环。文件公差来自作者，校准样例的 1800 mm 高度误差≤1 mm，不能据此把所有模板认定为人体尺寸合格。尚无全局自碰撞/舒适度/材料物理验证；模板作者需验证有效权重组合。许可文字为用户声明，不代替来源审查。导出自定义模板纸样仍要求确认工艺试制警告。

实现：custom-template.ts、CustomTemplatePanel.vue、schema/main/preload；校准样例与独立数值回归。

## 跨缝协调编辑

参考图 → 花纹节点编辑 → 选择花纹 → 源区域节点与跨缝协调编辑。修改一个源轮廓/孔节点，重新生成该源的所有视图和全部纸样片；共享缝交点来自同一源，允许整体改变交点。全部投影成功后以一个事务提交源纸样和所有花纹，可整体撤销/重做。任何一项失败保留全部原数据。

已有 UV 片内人工编辑必须明确勾选“确认替换”才能重建；不会自动覆盖。操作区显示影响范围。源本身有 3D 绑定时拒绝，需复制为独立区域；投影仍限正/背正交相机，域外、歧义、遮挡与过期绑定仍严格拒绝。当前为统一源节点协调，不是任意 3D 自由曲线/自动侧面补全。

实现：markings.ts/editMarkingSource、MarkingEditor.vue、marking.source.edit IPC、内部 marking.source.update 原子事务。

# 源花纹可视编辑与提取验收

日期：2026-10-08。最新程序由 `release/latest.json` 指定；最终测试、构建指纹和清理结果见 [61-final-audit.json](61-final-audit.json)。此前验收记录用于说明历史状态。

## 本轮修改

- 花纹详情直接显示源轮廓、孔洞节点和 Bézier 手柄，可拖动、Ctrl 点击插点、Delete 删除，也可把直线改为曲线。背景使用原图标定的逆变换，保持原有毫米坐标、花纹 ID 和部位分类。
- 添加／擦除笔刷和添加／减去钢笔路径在本地预览，点击“确认源花纹编辑”后一次提交。撤回笔画与取消不修改项目。提交成功后原图轮廓、模型贴附和制版花纹同步更新。
- 保存失败时保留完整草稿，在编辑窗口内说明原因。点击详情之外或切换花纹时，有未保存草稿则保留详情并允许继续编辑或明确取消。
- 已保存裁线、片内花纹和跨缝源节点改成可见节点选择与拖动；精确坐标只在高级模式显示。裁线节点命中使用实际显示的曲线，拖动使用真实模型表面射线交点。
- 自动贴附使用同一部位色块组成的注册坐标系。源形状变化时同步更新整组关联贴附，包含未激活模型；锁定关联和未授权的片内人工修改会阻止整个事务。明确替换人工编辑只适用于被编辑的源，不会顺便覆盖兄弟色块的人工修改。
- 项目版本检查、取消和几何验证在提交前完成，一次确认对应一次撤销。曲线的界面预检受采样预算约束，超预算交给后台验证，不因采样数多而误判合法曲线。

## 浅粉色、圆弧与部位分区

原问题首先来自色区识别：低饱和的粉色肉垫和内耳被合并到白毛，仅留下饱和的阴影岛。新判断要求邻域有足够的强粉色证据，再恢复浅粉；封闭高光只有在周围几乎都是粉色且边缘为低对比过渡时才合并。锐利的真实白孔与外侧白毛保留。

手爪的局部墨线用于区分相邻肉垫；内部未闭合褶线和单侧渐变阴影不单独生成色块。完整角色的部位推断增加下部双足轮廓证据，局部多色耳图不会仅因长宽比例被当作完整角色。部位仍是可修正的启发式结果，不是语义分割模型；不确定区域保留“待分类”。

真实原图固定样本与合成反例已加入回归：

| 样本 | 本轮结果 |
| --- | --- |
| 手爪原分辨率裁图 125×125 | 6 个独立粉色肉垫、4,496 像素，无伪白孔；各轮廓 58–106 个折线点简化到 10–24 个 cubic 节点 |
| 内耳原分辨率裁图 110×180 | 连续 3,139 像素内耳区域；210 个折线点拟合为 38 个 cubic 节点 |
| 白色圆孔、渐变高光、暖白毛、开放褶线 | 保留真实孔和白毛，恢复高光，避免褶线产生额外实例 |

上表曲线相对分割后栅格边界的保守误差上界约 1.18–1.38 原图像素。这是曲线拟合误差，不等于对角色真实解剖边界的识别准确率。轮廓和孔洞的拟合同时检查拓扑、偏差和尖角，失败时保留安全几何。

## 验证与使用

本轮增加源花纹后台几何／原子事务测试、自动关联组跨模型测试、实际 Vue 节点交互测试，以及发布程序的源详情鼠标操作测试。完整回归还覆盖导入、真实双视图、模型缩放、贴附渲染、裁线、制造、排料、分页 PDF、项目保存和恢复。最终通过数以同目录审计 JSON 为准。

Electron 自动化使用隔离测试项目；受限测试环境采用 `FPCAD_TEST_NO_SANDBOX=1`，生产启动配置没有因此关闭沙箱。节点组件测试含受控后台桩，用于交互验证；发布包套件和集成测试另外验证真实后台几何与持久化。

已有花纹不会随升级自动重算。保留旧项目后，可重新提取原图以使用新算法，或在花纹详情直接修补。没有强色彩支持的浅色、遮挡和同色阴影仍可能需要人工修正。一个源区域被擦成不连通的多个岛时会拒绝保存并保留草稿，应分别制作这些独立花纹。

# 左右预览与可调整布局

本轮依据用户截图替换固定等分布局。全部左右分栏调用唯一 `WorkspaceSplit.vue`，没有为每页复制拖动代码。

| 页面 | 左侧 | 右侧 | 3D |
| --- | --- | --- | --- |
| 花纹提取 | 双视图、标定、mask | 分类花纹库 | 无 |
| 模型管理 | 模型预览 | 模型库与调整 | 有 |
| 花纹映射 | 共享抽屉及模型预览 | 贴附、纹理、补全、路径 | 有 |
| 开裁 | 3D 模型 | 2D 候选；另有独立裁剪工具栏 | 有 |
| 制版 | 2D 单片预览 | 选择、编辑、打印及其他制版工具 | 无 |

分隔条有 8px 可操作区域，提供 pointer capture 以保证拖动越过边界仍能结束。CSS grid 比例轨道随容器即时变化，ResizeObserver 提供拖动和键盘操作所需的可用尺寸。页面隐藏期间窗口变窄，再次显示时也不会沿用旧像素宽度挤压右侧面板。正常尺寸下保持最小可用宽度；窄窗口按可用空间限制比例，面板内容滚动。

键盘左右方向键每次调整 2.5%，Shift 方向键每次调整 10%；Home 或双击恢复初始比例，End 移到允许的最大宽度。分隔条使用 separator 语义、可聚焦和当前比例读数。

开裁有两个独立分隔：3D 与 2D 预览之间，以及预览整体与右侧工具之间。所有页面的布局分别以 `fpcad.split.<storageKey>` 保存，重启或切换标签后恢复。比例不属于几何数据，不能影响 mm/cm 或输出 1:1 尺寸。

对应证据：`test-results/page-layout.json`、`test-results/page-layout-cutting.png`。UI 回归同时覆盖 1440 × 960 和 1000 × 680，另在隐藏页重新显示的第一个微任务检查宽度，避免只在 ResizeObserver 稳定后检查而漏掉闪烁和内容挤压。

局部查看通过唯一 `ZoomViewport.vue` 提供滚轮锚点缩放、按钮缩放、空格/中键平移与复位。标定、正背叠加、mask 三个预览分别保留自己的相机；简单正背图、花纹来源、纹理、排料和打印预览同样复用此模块。既有 3D 模型和 2D 裁片画布的相机继续独立工作。相机只改变查看范围；绘制时通过 SVG 逆变换获得像素或 mm 坐标，绝不把缩放比例乘入几何数据。交互、取消及验证见 [第 49 章](49-算法复核与局部缩放.md)。

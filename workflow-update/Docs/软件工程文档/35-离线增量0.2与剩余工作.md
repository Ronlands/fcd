## 数据与算法界限

- 2D 仍用稳定 outer nodes 加可选 holes / curves / notches / labels，而非完整 Path/Segment 聚合。节点间相邻边由开始/结束节点 ID 定义；拓扑改变后不能假装引用仍有效。
- 曲线递归细分依据控制点到弦段的距离 ≤0.01 mm；最多 2000 点，超限明确拒绝。孔暂为直线轮廓。
- 统一缝份可改变孔的尺寸；孔完全消失时阻断，不悄悄填孔。多个不连通 cut 外环仍需显式拆片。
- 排料保守使用包围矩形，不能宣称最优或已实现真实轮廓底左优化；已支持手工位置/旋转与锁定；自由实例保守排放在锁定区域下方。
- 3D 为正交 SVG CPU 预览，3000 顶点/5000 面；不是 Three.js 高性能场景、布料力学或通用大模型编辑器。
- 参数躯干由 Main 原创放样生成，不使用购入模型或假冒犬猫模板；数学制造检查与展开由 Rust 执行。围度的“精确”仅指无填充离散截面。
- 展开按 region 及连通域划分，要求单边界盘状 patch；没有 ARAP、自动 seam 搜索或重切优化。LSCM 最多 3000 CG 迭代，worker 总预算 10 s。拒绝翻转/重叠；合法但高失真只标 Needs Review。
- 默认躯干毛向从全局 +Y 切向通过三角 Jacobian 变换到纸样。任意导入面的无有效 +Y 切向时采用初始默认方向，必须由用户检查和设定；尚无完整材料方向/测量实体。
- UV 映射是有效三角域内的重心映射，域外返回失败，不吸到任意最近面。纸样边界自由变形不逆推身体；绑定与表面内容哈希/拓扑版本及纸样几何哈希共同失效。
- 参考图是 seeded RGB-distance 分割，尚无全图 Lab/HSV 聚类、曲线拟合、mask 画笔、相机遮挡投影、跨片连续性或语义分类；侧面保持未实现。
- 候选创建、接受及恢复为显式命令；展开/图像处理暂未接入通用可取消长任务 UI，已有 offset 作业仍可取消并拒绝过期结果。

# 全流程复验与跨步骤操作保护

本轮以用户的完整工作流、截图和异常操作保护要求为验收依据。先编写失败用例，再修复共享实现，最后复测正常使用和制造输出。

## 本轮修复

| 操作 | 原问题 | 修复后行为 |
| --- | --- | --- |
| 切换已保存模型 | 裁片和剪口保留，接缝元数据丢失 | 模型记录同时保存内部接缝，切换、撤销和 JSON/ZIP 往返后恢复 |
| 旧工程第一次切换模型 | 当前模型没有库记录时丢失其裁片和花纹 | 切换前保存当前模型快照 |
| 模型与独立裁片有接缝时切换；重新采用裁片 | 原接缝无提示删除 | 拒绝操作，提示先解锁并解除相关接缝 |
| 删除带花纹裁片 | 绑定和花纹路径残留，关联数据失效 | 原子清理该片绑定、UV 路径及来源依赖；其余裁片保持可用 |
| 删除原花纹 | 推断花纹留下过期来源 | 一次删除原花纹及未锁定推断；锁定依赖拒绝删除；撤销整体恢复 |
| 锁定接缝后改参数或解除关联 | 界面和接口仍可修改 | 前后端共同保护，显式解锁后可修改 |
| 导入失效且锁定的接缝 | 解除前无法解锁，项目难以修复 | 允许只改变锁定状态，再解除关联；修复前禁止打印 |
| 布尔替换有接缝或模型绑定的裁片 | 旧依赖留下或模型关联静默消失 | 提交前拒绝破坏依赖，模型裁片应改切分线重新开裁或复制为独立片 |
| 来源改变后再次展开 | 过期推断的指纹被更新，可能误通过输出检查 | 重映射之前核对来源和推断依赖，过期花纹拒绝参与制造候选 |
| 计算返回瞬间取消 | 已退出 worker 的结果仍提交 | 提交前检查取消；花纹映射、颜色切片与预览都属于同一个可终止任务 |
| 二维裁片局部放大 | 围绕窗口中心放大，无法保持鼠标处位置 | 复用其他预览的相机数学，围绕鼠标位置放大；无效输入及拖动期间缩放不生效 |

## 共用模块

- `apps/desktop/main/project-lifecycle.ts`：模型快照、跨模型依赖、锁定接缝、裁片路径清理及推断级联删除。
- `apps/desktop/main/repository.ts`：事务提交、撤销与重做；拒绝操作不写入项目或历史。
- `apps/desktop/main/markings.ts`：来源与推断的统一过期判定；输出与展开复用。
- `apps/desktop/main/cut-preview.ts`：展开、花纹重映射、颜色裁片及 2D 预览的完整计算链。
- `apps/desktop/main/surface-runtime.ts`、`apps/desktop/main/surface-worker.ts`：任务终止、子求解器清理、超时和结果校验。
- `packages/ui/viewport.ts` 与 `apps/desktop/src/modules/usePatternEditor.ts`：局部放大相机；显示缩放不改变 mm 几何。
- `SeamsPanel.vue` 与 `packages/ui/parameter-help.ts`：禁用受保护编辑并解释解锁、模型切换和重新开裁的处理方式。

保存模型新增可选的 seams 字段，旧工程仍可加载。失效边引用可以作为可修复草稿保留，但不会被当成合格制造结果。此前已丢失的接缝元数据不能可靠猜回，应回到旧恢复点或重新建立接缝；无关联剪口仍阻止制造输出，需先清理再配对。

## 完整工作流和异常限制

继续核对双视图拆分、部位分类、局部模型、抽屉贴附、曲面绘制、切分点与切线、颜色分片、二维微调、标签、材料、接缝、排料、JSON/ZIP 和项目恢复。全部请求方法的未知字段、越序调用、缺失对象、非法数值、重复提交、损坏文件、取消及写入失败仍由共用边界拒绝。具体预算和功能矩阵见 [第 47 章](47-全部功能与异常操作核查.md)。

打印单位保持 mm；cm 显示和导入按明确倍率转换。超大裁片按 A4/A3 有效区分页，保留重叠、行列页号、定位记号和 100 mm 校验尺。PDF 纸张尺寸与内容坐标按 72/25.4 pt/mm 校验，拼接还原后裁片及缝线的真实宽高不变。预览与输出都经过几何、材料、接缝、绑定和花纹审核；不会通过缩印或遗漏副本解决错误。

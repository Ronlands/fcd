## 确切边界

- 生成时保存**模块式服装壳**，可另执行**拼合为连续网格**：闭合单实体、去除内部交叠面，接点不足或多实体结果拒绝，不能把分离部件伪装为完成。模板配方 1.1.0 支持原有 1.0.0 快照。拼合改变局部围度与拓扑，实际胸/腰/臀/颈截面残差另表显示，输出必须确认工艺警告。仍不是通过试穿验证的连续解剖网格，未满足文档 I2/I5 的全部实体制造验收。未通过通用 Morph 测量求解、材料弹性/舒适度验证或自定义物种模板文件导入验收。
- 模块生成时胸/腰/臀/颈截面无填充匹配输入围度；实体拼合后的围度据实际截面重新测量，不冒充仍然匹配。填充使用离散法线偏移，残差表据实展示。总身高残差超过 1 mm 或不兼容参数组合拒绝生成。不能把一组默认参数通过等同于所有范围和组合已验证。
- 拼合表测量的是整个连通实体在对应高度的中心截面闭合周长。**龙翼在胸/腰高度与躯干连接时，周长包含翼缘，不能把它当作人体净胸/腰围**；原始躯干围度见模块测量表。默认龙的这两项残差约 +1844 / +1852 mm，明确保留，未伪装成测量拟合完成。默认拼合累计简化容差为 0.01～1.91 mm，参数变化可能超出预算而拒绝。
- 模型为 3000 顶点/5000 面上限的 CPU/SVG 几何预览。纸样与绑定上限增至 500，包仍 schema v2，新增字段可选；旧程序不保证读取新功能包。
- 自动切缝是确定性拓扑/法线启发式与有限试切，成本=0.85×面积加权 D+0.15×片数/maxPieces。制造补切可能提高片数与最终成本，因此分别保存试切优化成本 optimizedCost 和制造补切后 finalCost；不把后者强称为单调改善。没有证明全局最优、活动舒适度或完整身体只需 3～6 片。全身小部件可能生成数百片，实际工艺必须合片/调整分区。未收敛或高失真保留 Needs Review，不伪装为通过。
- 投影使用明确的正/背正交相机；不是透视相机求解、自动人体对齐、侧面补全或全图语义分割。侧面/遮挡没有源图覆盖时保持未知。等深重叠面拒绝为歧义。几何截断精度 0.0001 mm；大图/复杂片仍受 IPC、点数、worker 时间预算限制。
- 跨片交点来自同一三维源，初次投影保持统一来源；单侧纸样节点编辑不能移动共享缝交点。协调修改应编辑源区域并重新投影。尚无自动跨缝自由曲线编辑/整体连续性求解。
- 排料使用真实外环碰撞，但搜索是有限顶点候选启发式。矩形基线可能被保留；不承诺全局最优。默认不塞孔；方向集合受选项限制，完整材料 profile 尚未完成。
- 真实模板与曲面输出会触发小面积、窄片、失真等工艺警告；不得自动忽略。PDF 保留 200 页资源上限，大项目宜使用 A0/自定义纸张或分组制造。未执行实际打印/缝制/试穿。
- AI、商业后台、签名与跨平台发行继续按用户选择暂缓。默认生产沙箱保持启用；受限工具环境的桌面测试使用测试开关关闭 OS 沙箱，正常沙箱启动验收仍待完成。

## 操作

见根目录 [README](../../README.md)。正常启动 `npm start`，便携 EXE 以 `release/latest.json` 为准。3D 面板生成模板→可选实体拼合并复核实际截面→选择算法/自动切缝→检查报告与每面热图→审阅并接受；参考图面板选择二维区域→毫米对齐投影→编辑花纹节点；排料面板选择轮廓算法→核对完整布局→保存/导出。

## 算法依据

ARAP 使用原创实现，数学方法参考 [ETH ARAP 项目](https://igl.ethz.ch/projects/ARAP/)和 [SLIM 论文的 local/global 参数化介绍](https://igl.ethz.ch/projects/slim/SLIM2017.pdf)。实体拼合使用 [Manifold 官方 API](https://manifoldcad.org/docs/jsapi/classes/manifold.Manifold.html) 的实体并集及原始部件来源 runOriginalID，原始绑定版本固定为 3.5.4，Apache-2.0 归属文本随便携包保存；不打包该 npm 软件附带的 GLTF/命令行辅助依赖。ARAP 代码没有复制这些项目实现，也没有承诺其高性能或全局最优性质。

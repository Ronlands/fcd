## 已复现并修复的问题

| 问题 | 修复和验证 |
| --- | --- |
| 删除未激活模型使用的材料，随后模型无法正常恢复 | 材料依赖检查覆盖当前裁片、花纹库、保存模型和待接受候选；界面与数据库共用检查；拒绝后事务不变 |
| 开放路径的末端被当作闭合边 | 路径运算拒绝不存在的出边；SVG 已闭合轮廓明确传递闭合状态，保持正常导入 |
| 重复节点编号导致选中和移动对象不确定 | 输入校验拒绝外轮廓与孔洞的重复编号，以及重复曲线、标签和剪口编号 |
| 复制裁片遗留原接缝关联 | 副本中的配对剪口转为独立剪口，重新分配编号，原件不变 |
| 解除接缝仍留下生成剪口；一侧剪口错位仍可输出 | 解除关联清理该接缝生成的剪口并保留手工剪口；输出校验两侧数量、范围、方向和深度；单片输出仍检查另一侧 |
| 大量副本在限制触发前展开为大量坐标 | 导出与排料在分配前检查实例和点数；界面同步禁用超限输出；ZIP 可保留可编辑项目而不生成超限预览 |
| 纯空格项目或对象名称可通过接口 | 共享名称校验拒绝纯空白；界面和助手均受运行时校验约束 |
| 没有裁片仍生成空排料 | 服务层拒绝空项目排料，界面禁用相应按钮 |
| 拖动期间助手修改被旧快照覆盖；切换页面后仍提交拖动 | 核对拖动开始时的项目与版本及当前页面；旧拖动取消并提示重新调整；后台读取不能覆盖新提交 |
| 不存在的制作流节点可写入 | 节点清单提取到共享模块，页面导航和提交校验使用同一清单 |
| 名称达到上限后复制、布尔和纹理提取失败 | 派生名称保留后缀并限制长度，不截断 Unicode 字符；SVG 长标识转为有效显示名称 |
| 隐藏页面在窗口缩小后沿用旧宽度，右侧面板被挤压 | 分隔组件使用容器内的比例轨道与最小宽度，隐藏页显示时也立即正确；保留拖动、键盘、比例记忆和复位 |
| 大模型错误提示仍显示旧上限 | 提示直接引用导入预算常量；实际超限 OBJ 上传检查拒绝行为、提示和项目保持完整 |
| 损坏本地会话切换失败后仍改变当前项目；损坏活动会话阻止启动 | 切换前校验完整目标状态及资源，失败保留原项目；启动时只解除损坏会话的活动指向并提示，保留记录与恢复点，正常项目仍可通过界面打开和编辑 |

## 明确的处理边界

- 项目、制作流与 ZIP 文件上限 200 MiB；桌面请求 64 MiB，本机助手请求 2 MiB。
- 网格导入最多 200000 顶点和 200000 面；精确展开最多 50000 面。文件/计算还受各自的超时、输出大小和模板上限约束。
- 项目最多 500 裁片、500 花纹库区域、30 保存模型、2 参考图。单片裁剪数量 1–100；轮廓与单孔最多 2000 点，最多 32 孔。
- 每次制造输出或排料最多 2000 个裁剪实例及 1000000 个展开输出坐标；复杂花纹与孔洞按副本数计入。超限应减少选择或副本，不会自动缩放或删减产物。
- 打印计划最多 200 页；页边距至少 6 mm，可打印宽度至少 100 mm，重叠必须小于有效打印跨度。页号须存在、唯一且非空。
- 自动候选与长任务受取消、超时及旧版本检查约束。取消文件对话框不修改项目；保存失败不标记为已保存，临时文件清理，允许保留新的安全恢复点。

## 共用实现与复验

依赖检查位于 `packages/manufacturing/dependencies.ts`；制造预算位于 `packages/manufacturing/output-limits.ts`；剪口与接缝检查位于 `packages/manufacturing/seams.ts`；制作流节点清单位于 `packages/workflow/nodes.ts`；名称规则位于 schema 与 `packages/schema/names.ts`；交互状态由 `apps/desktop/src/modules/usePatternEditor.ts` 管理，分隔布局由 `WorkspaceSplit.vue` 管理。

新增回归：`tests/integration/operation-guards.test.ts`、`tests/integration/editor-races.test.ts`、`tests/operation-guards-e2e.mjs`、`tests/corrupt-session-e2e.mjs`。桌面异常脚本覆盖全部 52 个请求方法的严格字段边界，并验证缺失对象、越序调用、错误输入、并发提交、损坏文件、取消、保存失败和剪口修复。损坏会话测试直接破坏隔离数据库中的活动记录后重新启动，通过正常界面选择另一个项目并编辑，最后确认损坏记录与恢复点仍存在。布局回归包含窗口变化后立即显示隐藏页的检查。原有完整业务测试继续运行。

最新日志和统计在项目 `test-results`，原失败汇总保存在 `test-results/desktop-attempts`。测试在隔离工作库执行，记录测试用 sandbox 配置；生产启动参数未添加测试用配置。

实体打印机和材料成品尚未实测。软件层验证毫米尺寸、分页、定位标记、校验尺和打印调用；实物输出应使用 100%/实际尺寸，并用 100 mm 校验尺核对打印机设置。

原目录受写入限制，原源码及工程文档没有被覆盖。修订位于 `workflow-update`，可用根目录 `启动新版FurryCAD.cmd` 启动；文档同步补丁是完整源码补丁的子集，不重复应用。

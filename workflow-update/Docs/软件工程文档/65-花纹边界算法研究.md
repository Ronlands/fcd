# 花纹边界算法研究与部署判断

检索日期：2026-10-09。研究目录：`D:\Codex\furrycad\workflow-update`。本报告区分「论文/官方仓库能力」「本机可运行条件」与「已在固定原图验证的结果」；没有把模型名称、发布时间、通用分割榜单当作本项目质量验收。

## 结论

当前任务需要三个不同答案：像素属于哪种实际毛色、同色像素属于哪个独立物体、栅格边界怎样变成制造可用的曲线。SAM 的物体 mask、去阴影模型的反射率图、矢量化工具的 SVG 各自只覆盖一部分。直接换成最新 SAM 3.1 不会自动获得准确的毛色裁片。

沿现有 Windows Electron 离线交付路径，可直接验证并交付的是**材料颜色连续性 + 受约束线稿分隔 + 带拓扑保护的曲线拟合**。本次选择依据是任务适配度与已验证结果；用户没有禁止新增依赖。本机尚无 SAM/Intrinsic 推理环境或权重，本轮没有把未执行的模型推理记为效果改进。后续交互式分割实验可比较 EfficientViT-SAM 的完整 ONNX encoder/decoder 与 SAM 2.1 点/框提示；语义模型只建议角/耳对象 mask，毛色仍在其内部提取。

2026 年最贴近「原画去阴影」的专门论文是 Workflow-Aware Structured Layer Decomposition，它直接分解线稿、平涂、阴影、高光，但论文给出的仓库在本次网页读取及 GitHub API 查询均为 404，无法核实公开代码、LoRA、权重与部署许可。它不能作为现在已可用的产品依赖。[论文与作者声明的仓库](https://arxiv.org/html/2603.14925v1)、[仓库链接](https://github.com/zty0304/Anime-layer-decomposition)。

## 去阴影、平涂与2026年图层分解

**Intrinsic/Ordinal Shading/Colorful Diffuse Intrinsics（2023/2024）**：任务直接涉及albedo/shading，有研究价值。但官方实现为academic use only、patent pending，不能当作默认可商业分发组件。物理反射率分解针对照片，其假设无法保证覆盖紫/粉色投影、cel-shading、画师刻意添加的白高光和真实粉垫；有彩色阴影不等于每个异常色相都能自动抹掉。[作者官方仓库与许可](https://github.com/compphoto/Intrinsic)。

**Workflow-Aware Structured Layer Decomposition（2026-03）**：四层目标最贴近需求。论文使用Qwen-Image-Layered加LoRA与layer embeddings，报告45个训练样本、108个生成测试样本，768×1152；RTX PRO6000 Blackwell训练约40h，同GPU推理约2min/图。本图为带角、毛尖、肉垫的兽人设定图，不能由这些测试推断已泛化。仓库网页与API在2026-10-09均404，尚未确认任何可下载adapter或代码许可；论文CC-BY不等同于模型权重许可。[primary论文](https://arxiv.org/html/2603.14925v1)。

**Qwen-Image-Layered（2025-12/CVPR2026）**：官方公开20B BF16模型，Apache2；原生RGBA图层分解，提供640/1024 bucket和默认50步推理。仅参数BF16约40GB的计算下界已经超过16GB显存，CPU offload/量化可以另行研究，但没有本机峰值/速度/稳定性证据。它的通用语义/结构图层与专门「flat/shadow/highlight」层不是同一种已验证能力，不能拿通用基座冒充缺失的专门LoRA。[官方模型卡](https://huggingface.co/Qwen/Qwen-Image-Layered)。

**Qwen-Image-2.1（2026-09-20）**：官方新模型为7B视觉生成组件，支持透明图、局部编辑和抠图；许可变为Qwen Research License，商业用途须另行取得许可。比20B更小、更新时间更近并不能证明花纹边界更准，且生成编辑可能移动毛尖或重画花纹，应仅作为研究对照。[官方模型卡](https://huggingface.co/Qwen/Qwen-Image-2.1)、[官方许可](https://github.com/QwenLM/Qwen-Image-2.1/blob/main/LICENSE)。

**See-through（SIGGRAPH2026）**：已经公开代码/权重，官方pipeline约12–16GB VRAM@1280，并提供group offload/NF4。现有GPU可能满足显存条件，现有Python与依赖环境不满足。V3标签在作者代码中为23个人体/服装部位，含ears、tail、wings、objects，没有horn；模型将遮挡区域补画成完整RGBA部位，不能直接当测量真值。它按部位分层，部位的阴影仍可能与颜色共存。仓库Apache2；LayerDiff/Marigold权重继承OpenRAIL限制，商业允许但重分发须保留相应限制。19类SAM-HQ body parser权重Apache2，但同样没有horn类别。[官方仓库](https://github.com/shitagaki-lab/see-through)、[实际标签定义](https://github.com/shitagaki-lab/see-through/blob/main/common/live2d/scrap_model.py)、[LayerDiff权重许可](https://huggingface.co/layerdifforg/seethroughv0.0.2_layerdiff3d)、[SAM部位parser权重许可](https://huggingface.co/24yearsold/l2d_sam_iter2)。

**平涂/漫画实例方法**：Flat Magic的U-Net+trapped-ball流程服务于线稿填色，依赖torch/OpenCV/scikit-image/Cython，公开实现GPL3；不应因为名称flatting就视作成熟的彩色原画去阴影器。CartoonSegmentation主要识别整个人物实例，其instance mask不会自动提供毛色裁片。[Flat Magic官方代码与说明](https://github.com/Nauhcnay/flat_magic_backend)、[许可](https://github.com/Nauhcnay/flat_magic_backend/blob/master/LICENSE)、[CartoonSegmentation官方仓库](https://github.com/CartoonSegmentation/CartoonSegmentation)。

## 可立即部署的传统方法及边界

**颜色/材料恢复**应在固定前景内计算。只按HSV hue family有不可避免的阈值断层：白毛投影变暖时可落入pink，阴影从黄变褐时可落入red，邻近色带的真实边界又可能同样平滑。白/蓝/黄基色种子应来自有支持的亮部，亮度差降权，饱和度/色差/颜色投影误差用于约束传播；最终输出材料标签与confidence。真实粉垫/内耳需要高置信区域支持，不应把所有红色都合白；对阴影的判断必须同时使用局部邻接、跨尺度色彩连续性和线稿结构。

**Guided/bilateral/edge-aware滤波**能去JPEG细噪声和稳定抗锯齿边缘，不能凭平滑推断「这里是阴影」。以原图亮度为guidance时，强阴影边缘也会被保留或转移到标签。适合对已判定的材料概率做有限半径修正，禁用跨颜色/物体边界的高半径模糊。Guided Filter作者Matlab示例许可为academic-only；可以研究论文、选择许可合适的独立实现，不能直接复制该示例到生产。[作者论文](https://kaiminghe.github.io/publications/eccv10guidedfilter.pdf)、[作者代码入口](https://people.csail.mit.edu/kaiming/eccv10/)。

**Marker-controlled watershed / geodesic生长 / graph-cut类方法**适合分开同黄物体，但决定质量的是种子和可跨越代价。未经筛选的梯度watershed会把大量阴影、毛褶切成小区。把两侧亮部支持的窄暗谷作为局部divider，再在材料mask内进行多种子生长，可让角与耳黄分别覆盖线稿。局部暗谷不能直接等价于独立物体；应同时检验分隔是否连接现有区域边界、种子面积/形状是否有意义，避免封闭阴影制造新裁片。完全同色且无可见分隔的像素需要语义/人工证据，单一图像没有唯一数学答案。[OpenCV marker watershed官方说明](https://docs.opencv.org/4.x/d3/db4/tutorial_py_watershed.html)。

**矢量化**必须位于材料和实例判定之后。VTracer现有MIT/Rust/Windows路线，支持spline、watershed和fixed palette，可作为边界后处理对照；其默认stacked SVG为显示采用覆叠形状、避免holes，这与真实裁片孔洞并不等价。它忠实描摹输入色区时也会忠实描摹错误阴影。DiffVG/CLIPasso是可微渲染/抽象线稿优化，不是可直接保证公差、孔洞和完整毛色覆盖的CAD转换器。[VTracer官方说明](https://github.com/visioncortex/vtracer)、[DiffVG作者实现](https://github.com/BachiLi/diffvg)、[CLIPasso作者实现](https://github.com/yael-vinker/CLIPasso)。

## 评估协议与交付判据

第一阶段不引入模型：保留原图像素，分开材料标签、实例ID与部位标签。材料层先减少暖/冷白毛阴影碎片；结构层只在证据支持的位置分开角/耳/头；轮廓层共享边界并做尺度适应拟合。每层失败都应能显示原图局部、输出mask与修正原因，人工边界继续可用。

先人工标记本图前后各组：亮白/粉影/紫影同材质点对、黄/褐同材质点对、粉垫/内耳保留点、两角和邻近黄色耳/额毛不同实例点、毛尖/真实孔洞。它们验证不同错误，不能合并成「分区数量正确」断言。加少量原图polygon/边界作为目视真值，至少一幅不同作者的未用于调阈值原图做留出评估；当前只有一张原图不能声明普遍最优。

| 实验 | 自变量 | 主验收项 | 必须防止的回归 |
| --- | --- | --- | --- |
| 材料恢复ablation | 现有HSV / 新材料连续性 / 加guided局部概率滤波 | 阴影点对材料一致率、错误新材料面积、材料边界F1 | 粉垫、内耳、黄白蓝真实边界被抹除 |
| 同色实例分隔 | 现有硬ink / 局部软暗谷+marker geodesic / marker watershed | 角与黄毛不同owner；原图局部边界偏差 | 每条封闭阴影都生成裁片、跨背景/细条漏出 |
| 曲线拟合ablation | 原栅格 / 保角拟合 / spline外部对照 | p95/最大边界距离、节点数、孔洞、自交、面积误差 | 毛尖圆钝、窄带塌陷、真实sharp corner位移 |
| 可选交互模型 | EfficientViT-SAM完整ONNX / SAM2.1tiny / gated SAM3 | 相同点/框/负点下的角mask IoU、BoundaryF1、泄漏率 | 模型分整头、细黄条消失、自动置信度代替人工验收 |
| 本机离线部署 | 冷启动/重复提示/CPU回退/取消 | p50/p95耗时、RSS/VRAM峰值、失败回退、无网络推理 | 首次运行隐式下载、UI卡住、改变用户Python环境 |

模型实验尚未运行，不能填写虚构IoU或本机速度。实施前必须明确冻结权重/许可证/sha256、图像前处理、原图坐标还原、运行时版本与失败回退。实验输出可采用与现有 `illustrationRegions` 相同的像素mask接口，再通过 `maskPieces` 的拓扑验证/拟合进入制造层。模型的分辨率与confidence必须记录，生成补画的不可见部分只能作为待审阅推断。

本报告支持当前可部署方案的选择，同时保留模型升级的具体、可复现评估路线；最终程序实现、完整检查和用户原图视觉验收由本轮实际改动记录另行给出。

## 独立整合审查：资源回归与修复

独立审查发现初版 `structureInstances` 对每个面积≥256px的黄色连通块均分配整图大小的domain/depth/barrier，并最多执行三次整图marker扫描。普通实色色块没有分隔证据也执行这些扫描，使初版复杂度由基础分区的整图扫描放大为「色块数×整图像素数」。512×512图中256个16×16实色块，基础分区22.1ms而初版结构分隔9491.5ms；1024×1024同样256块初版35480.5ms。这些输入未超过500个区域上限，不能依赖结果复杂度检查防止耗时。

修复改为每个色块的局部包围框，按最大检测半径padding，局部执行暗谷检测/marker扫描/geodesic填充后还原原图索引；完全没有ink或深度证据的块直接保留。相同独立探针观察到512²/256块36.6ms、1024²/256块136.1ms。以上均为本机单次观察，不应被当作稳定p95指标。

新增 `tests/integration/structure-resource.test.ts` 用扫描域大小、准确原图索引、顺序与完整覆盖验证资源上界，不使用脆弱的wall-clock断言：256个平色块仅保留两次基础整图扫描；64个带分隔线的独立色块，额外扫描都限制在≤42×42的padded局部域。原7项结构回归与2项资源回归通过；本段不代表全套整合检查结果。

另用独立合成图确认方法的语义限制：同一黄色区域中，贯穿两侧边界的1/3/5/7/9px同色相暗带均会分成两个实例。它在像素外观上与狭窄绘制线稿可以相同，现有局部亮度证据不能保证判断艺术意图。固定原图的尾/腿阴影保持回归通过；不能由此宣称所有跨边界窄投影都不会误拆。没有根据这一歧义随意调整阈值、重画不可见边界或吞并真实材料。

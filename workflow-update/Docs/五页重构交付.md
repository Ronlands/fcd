# 五页重构交付

界面依据用户最新图片三、图片四重构。导航顺序为 **花纹提取 → 模型管理 → 花纹映射 → 开裁 → 制版**。

花纹提取与制版没有模型预览。模型管理、花纹映射、开裁共用一个 3D 实例；开裁左 3D / 右 2D 可拖动调整，其他页面和工具区域使用同一分隔组件。功能按模块文件组合，制作流程及 JSON 位于制版次级标签。

原目录 `启动新版FurryCAD.cmd` 启动本目录版本。软件工程文档已按最新要求重写主要章节，其余技术/历史章节附带入口更正，规范入口是 [46 章](软件工程文档/46-五页职责与共享功能模块.md)。原目录受限文件没有被覆盖，独立文档补丁用于同步原目录。

验证详见 `test-results/desktop-verification.json`、`test-results/unit-integration-verification.json`、`test-results/page-layout.json`。毫米几何、A3/A4 分页拼接、打印、ZIP 和 JSON 的原业务测试持续保留；未进行实体打印或材料成品验证。

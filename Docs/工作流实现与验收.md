# 五页工作流实现与验收

日期：2026-10-07。完整实现位于 `D:\Codex\furrycad\workflow-update`，从父目录“启动新版FurryCAD.cmd”运行。

本轮界面依据用户最新图片及文字，不再按历史文档的页名或旧排序安排功能。主导航依次为花纹提取、模型管理、花纹映射、开裁、制版。

## 模块与边界

| 页面 | 入口模块 | 主预览 |
| --- | --- | --- |
| 花纹提取 | MarkingsPage、ReferencesPanel、MaskEditor、MarkingLibrary | 原图和分类花纹，无模型 |
| 模型管理 | ModelManagementPage、ModelTools、ModelLibrary、CustomTemplatePanel、MeshEditPanel | 3D |
| 花纹映射 | MappingPage、MarkingLibrary、TexturePanel、InferenceTools、MarkingRecords、MarkingEditor | 3D 与局部路径编辑 |
| 开裁 | CuttingPage、SurfaceCutPanel、CutLinesPanel、UnwrapTools、PreviewPiecePicker | 左 3D、右 2D 候选 |
| 制版 | PatternPage、PatternProperties、CutSelection、LabelEditor、AllowancePanel、AdvancedTools、MaterialsPanel、SeamsPanel、NestingPanel、WorkflowPage | 2D，无模型 |

页面组合现成功能模块，不复制功能。ModelViewport / SurfacePanel 为唯一 3D 实例，PatternCanvas / usePatternEditor 为唯一二维实例和编辑状态。WorkspaceSplit 是统一分隔条，支持拖动、方向键、恢复默认和每页比例记忆。

## 业务链路

上传并按正背面与颜色拆分 → 分类保存 → 选择或上传自动保存的模型 → 花纹映射贴附及路径补全 → 开裁设置切线与新增点 → 审阅颜色与失真的 2D 候选 → 接受进入制版 → 二维调整/标签/单片或全选打印 → 裁片 ZIP 或制作流 JSON 保存、导入继续修改。

三维贴附保留原始来源与重心片段；拓扑细分保持颜色和可用 UV。候选计算不覆盖最终裁片，接受可撤销。二维物理坐标、纸张、切分点和标签统一为 mm；显示 zoom 不影响输出比例。分页打印保留重叠和定位信息，原生打印与 PDF 使用相同物理纸张。

制版次级标签包含材料、接缝、排料、制作流程。节点编辑跳转到对应主页面或次级标签，制作流 JSON 和裁片 ZIP 使用原有完整项目交换服务。

## 验证

类型检查、构建、自动测试、Rust 测试及桌面验收报告位于 `test-results`。`page-layout-e2e` 检查五页边界、单实例、从模型进入开裁后的草稿挂载、相机状态、跨页快捷键、拖动与键盘、刷新恢复和窄窗口。其他桌面测试保留真实双视图、比例、模型库、贴附、裁剪、标签、保存恢复、打印、ZIP、JSON 断言。

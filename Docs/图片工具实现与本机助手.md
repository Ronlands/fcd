2026-10-06，当前可运行版本位于 `D:\Codex\furrycad\workflow-update`。双击父目录的 `启动新版FurryCAD.cmd` 启动。五个工作页面和实际尺寸打印流程均保留。

## 花纹映射与开裁页面

花纹映射页从共享抽屉获取来源并贴附到模型；开裁页设置切分工具及展开参数，左侧模型与右侧二维候选可拖动调整宽度。制版的制作流程次级标签包含裁剪线组节点，点击“编辑此节点内容”会进入开裁的对应线组编辑器。

| 绘制部件 | 模型上方选择允许钢笔/自由绘制落点的部件；截面工具另有部件选择。默认全部选中。 |

保存切缝会更新真实拓扑、共享边、旧线组和纹理 UV，并重新映射已有花纹。改变路径、启停切缝或半侧范围后，重新计算并审阅展开候选，再输出。单纯改名保留已有有效裁片绑定和花纹路径。

### 几何精度与范围

- 所有长度和坐标以 mm 存储；cm 仅做换算显示。控制点限 400 个、线组限 200 个；钢笔样条细分容差 0.1 mm。投影检查预算为采样点数乘网格面数最多 2000 万，超限拒绝该操作。
- 钢笔/自由绘制沿当前正交视图贴到最靠近观察者的可见面。不能跨越模型外空白；遇到范围外路径或镜像侧缺失，会拒绝并保留原项目。更换视角画另一组线可以覆盖背面或侧面。
- 数值交点形成退化短边时，仅在网格连通关系合法的前提下合并小于 0.0001 mm 的短边。已有切线与花纹随之同步。
- 迭代求解因细长三角面失败时，共面且拓扑为圆盘的片可用精确毫米投影；曲面继续由原求解器处理。报告记录 `planarExact`。轮廓冗余采样清理全局偏差上限 0.0001 mm，记录 `boundaryToleranceMm`；所有面和 UV 映射保留。
- 导入/显示最多 20 万面，精确展开最多 5 万面。曲面仍有失真报告和制造检查，不能由界面功能替代材料与实物试缝。

## 本机助手连接

按用户选择实现受控本地接口。顶部“允许 AI 助手连接”开启后，显示本次启动的地址与令牌；默认隐藏令牌，按“显示”可查看并复制。本机助手需要支持 HTTP 工具调用；接口不会自行启动模型或发送项目到外网。

默认关闭。接口仅监听 `127.0.0.1` 的随机端口，使用 256 位随机令牌和 Bearer 鉴权。关闭连接会停止监听并撤销未执行请求的权限；重新开启更换令牌；重启不会自动授权。并发开启共用一次启动；关闭后重开会建立新授权，旧启动不能覆盖新连接。拒绝浏览器 Origin、非本机 Host、无令牌请求、非 JSON 和超过 2 MiB 的请求。最多 4 个未完成请求、每分钟 120 次请求。

鉴权后可用 `GET /v1/status` 查看连接状态、操作列表和最后请求时间，响应不含令牌。用 `POST /v1/request` 调用项目协议，例如读取当前项目：

```json
{
  "protocolVersion": 1,
  "requestId": "12345678-1234-4123-8123-123456789abc",
  "method": "session.read",
  "payload": {}
}
```

请求头为 `Authorization: Bearer <界面令牌>` 与 `Content-Type: application/json`，地址为界面显示的 `/v1/request`。每次新请求使用新的 UUID；重复同一修改请求会返回已完成结果，不重复执行。

读取结果中的项目 `id` 和 `revision` 后，修改请求同时附上 `projectId` 与 `expectedRevision`。例如 `method: "command.apply"`，`payload: {"type":"project.rename","name":"新项目名称"}`。旧版本修改返回 409，助手应重新读取项目后确认修改内容。成功修改进入同一撤销/保存流程，并同步更新界面。

操作白名单允许查看项目、验证、撤销/重做、花纹贴附/修订/推断、切线与半侧编辑、裁片编辑、展开候选与采用、材料/接缝/制作节点调整、排料及打印预览。当前状态接口返回完整方法和命令列表。直接注入原始网格、文件对话框、文件导入导出、系统打印和会话切换不对本机助手开放；这些操作通过界面完成。

## 打印和验证

大于一张 A4 的裁片仍按 1:1 输出，提供整幅拼接图、逐页预览和选择页面补印。A4/A3 背景、毫米坐标、重叠边界、对应十字标记和每页 100 mm 校准尺共用相同分页计算。详情见 [单位与分页打印核查](功能单位与分页打印核查.md)。

验证：类型检查、桌面构建、186 项自动测试（39 个文件），以及 21 套桌面验收。新增测试覆盖真实切缝、相交线连续性、截面闭环、左右半侧面积、对折缝份、纹理 UV、花纹覆盖、改名后的制造绑定与推断依赖、重启/文件恢复，以及本机接口真实修改和权限限制。

证据：`test-results/unit-integration-verification.json`、`test-results/desktop-verification.json`、`test-results/cut-tools-verification.json`、`test-results/cut-tools-model.png`。系统打印入口使用测试回调，未连接实物打印机；首次输出按 100% 打印，量 100 mm 尺应为 10 cm，再试缝。

本次复验还恢复了花纹映射抽屉的“既有二维区域贴附”入口。项目版本变化后，裁片打印、总导出和展开候选的旧审阅确认失效，包括本机助手的外部修改。详情见 [项目流程复验与修复](项目流程复验与修复.md)。

# 离线 0.6：交换格式、路径编辑、测量与视图

日期：2026-10-05。此记录描述实际实现及验证范围，保留原始设计目标，不把开发预览等同于制造/发行验收。

## 已接入桌面的功能

- SVG 纸样导入：4 MB；绝对 mm/cm/in/pt/pc/px 尺寸，缺省 CSS px=25.4/96 mm，viewBox 与 preserveAspectRatio；分组及 matrix/translate/scale/rotate/skew 变换；闭合 M/L/H/V/C/S/Q/T/A/Z（含相对、隐式重复与指数数值）；path、polygon、矩形/圆角矩形、圆和椭圆。三次曲线保留控制点，二次精确转三次，孔曲线按 0.01 mm 离散；evenodd/nonzero 嵌套孔与岛均保留。交叉子轮廓、开放路径、不支持的效果/实体/相对单位明确拒绝。SVG 是制造轮廓导入，不能把任意视觉文档默默变成刀线。拒绝脚本、DOCTYPE/ENTITY、外链、use、滤镜、裁切与蒙版等。深度64、元素10000及交叉检测200万次有界；片数/节点仍遵循项目限制。
- GLB 导入：嵌入资源的静态三角网格，默认场景及父子世界变换、实例、索引/非索引图元、反射绕序；每个节点内精确同坐标顶点合并，避免 UV/法线分裂导致虚假裂缝。glTF 米转内部毫米，导入缩放默认1。4 MB，3000顶点/5000面，解码前 accessor/node 数量预算。外部资源、动画/骨骼/未烘焙 Morph、需扩展解码的压缩网格和非三角图元拒绝。仅使用 SDK 内存读取，不解析外链文件。导出静态 GLB 使用米、float32 顶点和分区 extras；是几何交换，不表示布料模拟。OBJ 无单位，须在导入框确认单位到毫米的比例。
- 精确边细分：De Casteljau 及真实弧长重映射；缝合关系按双方方向同步分段，吃量/公差按区间分配，保持锁定状态。刀口、连续缝份采样同步更新。几何形状未改变时仅更新匹配原 hash 的绑定与花纹来源；已过期的关联不被重新认定有效。一个事务，可撤销/重做。
- 路径修剪、反向连接和闭合：从当前节点沿路径保留至结束节点，至少3点；连接两条开放路径，端点≤0.01 mm，材料与制造参数一致。控制柄、刀口弧长站位、缝份方向、标签与有效接缝引用重映射。孔洞依赖、会删除的接缝引用、不同蒙版来源明确拒绝。开放路径可编辑，但阻止制造导出；改变轮廓形状仍须重新展开，不能伪造原3D绑定继续有效。
- 配对剪口：接缝表的“生成配对剪口”，1～20个内部等距站位，遵循双方反向和弧长区间、声明吃量；保持人工剪口，重新生成仅替换该接缝生成的剪口。先校验接缝和制造几何，全部成功后一笔事务。细分时自动剪口的接缝来源随所属分段更新。
- 透视预览：正/背/左/右快捷视角，可切正交/透视；点击用相机距离校正屏幕重心权重后映射至纸样。跨片参考花纹的制造投影仍使用明确正/背正交模型，不把透视预览当作相机标定。
- 正背图对齐：两图分别标定同一实物A/B及真实距离，公共毫米原点与+Y；提供背面镜像和透明叠加检查，保留独立标定与候选来源。它是人工双基准对齐，不自动猜测遮挡/相机内参。
- 六种内置模板实测拟合：以离散外壳实际高度、围度、头宽/高、尾中心线及肢体围度为目标；保留填充与材料层厚，有界12次/5秒，1 mm公差，不可达/异常目标/左右共用参数冲突拒绝。输出实际残差、迭代和目标快照，保持可保持的ID。实体拼合后的测量需独立复核，不能直接用模块参数冒充拟合。
- 自定义模板显式 Morph 权重：使用定义的权重边界；实际测量写入快照，继续通过已有范围、退化和翻面门禁，不执行模板脚本。
- 局部雕刻/平滑：毫米球形范围、平方衰减、强度与位移或邻域平滑；保存原来源/hash、影响顶点数量，保持拓扑ID，拒绝退化或相对于编辑前面的翻转；撤销恢复整个网格。原始模板与来源仍保留，重新生成/拟合会替换雕刻。旧展开和花纹显式失效，需重新计算。未提供全局自碰撞或材料受力保证。

入口：3D/展开中的 SVG、OBJ/GLB、静态GLB、内置拟合、Morph、雕刻与相机；纸样属性中的路径修剪/连接；接缝中的配对剪口；参考图中的双视图叠加。

## 性能与可靠性

几何 worker 改成有界批处理，避免合法多片项目仅因汇总响应超过管道限制而失败。缓存按访问刷新且覆盖500片；本次读出的结果独立保留，淘汰历史缓存不影响当前状态。3D失真和花纹按面建立索引，移除每帧每面线性搜索。

500矩形片的真实IPC/归档与重复缓存读取已覆盖，实测见 evidence/0.6.0/performance.json 和 completion-e2e.json。它只证明所测范围，不是18文档的20万三角形/100片各100段完整性能认证。本版本制造网格仍限制3000顶点/5000面；20万面LOD和5万面展开目标**尚未实现**，不是“全部功能已完成”。

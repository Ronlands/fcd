# 曲线、模型表面编辑与渲染验收

本轮由三个 GPT-6.1-sol / high 子任务处理轮廓拟合、已贴附花纹编辑、模型渲染；主任务实现后端事务接口，审核共享几何、相机与坐标转换，整合到同一维护目录，并用最终打包程序验收。具体构建标识、测试结果和清理状态见 `60-final-audit.json`。

## 交付行为

### 原图轮廓

- 用整段原始边界样本拟合三次 Bézier 曲线，替换短手柄堆叠形成的像素折线。
- 根据多尺度边界方向保留稳定的尖角、凹口和窄缝；平滑连接维持切线连续。
- 独立核对曲线与原边界的双向误差、面积、孔洞、自交和相邻区域，拒绝越界或破坏拓扑的平滑结果。
- 实际角色图黄色耳缘回归样本由 164 个栅格边界点变成 11 个曲线节点，保守双向误差约 1.389 个原图像素（阈值 1.4）。此结果说明该样本的轮廓质量，不代表所有绘画边界都能完全自动识别。
- 已有项目保存的轮廓不被静默改写。需点击“按当前标定重新拆分”应用新版提取，再核对结果。

### 已贴附花纹

- 直接点击模型上的花纹选中，左键拖动移动；一次松手形成一次保存与撤销。花纹身份不变，跨接缝的所有裁片花纹同步更新。
- 加色笔刷使用连续圆头扫掠，擦除笔刷保留孔洞。半径以毫米设置，单笔只提交一次；超出预算、完全擦空或切成多个独立岛时保留原记录并解释原因。
- 节点编辑支持外轮廓、孔洞节点、Ctrl 点击插入、Delete 删除、确认与 Esc 取消。工具栏用独立笔刷、橡皮和节点图标区分操作。
- 草稿保留世界坐标编辑平面。中键旋转、Shift＋中键平移、滚轮缩放与花纹编辑配合使用；过于侧向的投影不接受不可靠的节点输入。
- 旧贴附记录按真实面片边界恢复路径，消去共享边，不用凸包填补缺口；无法安全恢复的复杂／折叠／不连通情况明确拒绝。
- 新增接口使用版本检查、锁定依赖检查、取消与超时、一致性验证和原子提交。画笔／拖动失败不留下部分修改。
- 按颜色裁切后的花纹仍可继续编辑，但旧颜色切缝会标记失效，重新裁切后才允许制造输出。

### 模型预览与制造

- 默认中性实体材质，使用角度加权法线改善曲面明暗，保留真实硬边；显示光照不改变制造网格或毫米坐标。
- WebGL 用真实三角面上的重心坐标与奇偶遮罩显示凹轮廓和孔洞，正确处理后方遮挡。节点、裁剪线及笔刷提示与模型共享视口。
- 修复 GPU 内画布被旧 CSS 压缩到 80 像素，导致预览与鼠标命中位置不一致的问题；验证多个窗口尺寸下画布与覆盖层完全对齐。
- Canvas 备用渲染插值曲面光照；修复 HSL 失真热图颜色被十六进制解析器破坏的问题。
- 修复连续修改裁剪线时，公共边上的浮点误差导致 `CUT_OUTSIDE_SURFACE`，以及瘦三角形把边上点误作内部点导致退化网格的问题。保留真实模型外路径拒绝检查。
- 回归确认真实毫米尺寸、通用模型缩放、对称裁剪、半侧展开、分页 PDF 与校验尺；预览缩放不改变输出尺寸。

## 验收方法

- 类型检查、全量单元／集成测试、Rust 几何测试、构建与重复打包检查。
- 最终程序运行 40 组桌面回归，覆盖新建／恢复、导入、提取、钢笔、贴附、裁剪、制版、打印导出、异常操作、生命周期和大模型。
- 新增实际窗口用例验证点击、跨接缝拖动、加色、擦除孔洞、节点插入／删除、草稿取消、相机控制及保存次数；核对实际项目几何和修订号。
- 渲染测试读取像素验证颜色、孔洞、凹口、深度遮挡、布线、热图、阴影和相机更新。旧 SVG 元素数量断言改成可见像素与原始几何核对。
- 共享边修复用实际 UI 产生的坐标复现“绘制→插点→调整→继续绘制”；验证对称路径连续、总面积 40000 mm² 不变。另验证 0.0001 mm 窄面内路径通过，而附近模型外路径仍拒绝。

测试环境使用隔离项目目录；Electron 自动化启动按环境要求禁用 OS sandbox，WebGL 专项使用软件驱动。生产启动配置没有因此关闭沙箱。自动化不等于不同显卡、打印机或实际材料上的实物试制认证。

## 使用边界与清理

本轮改进的是可见边界拟合与表面编辑，不声称能从被遮挡的原图唯一恢复真实花纹。大面积阴影与真实色块歧义仍需选区修正。对不连通的花纹应分开制作；超出安全投影条件的旧记录需要从合适视角重建。

完成验收后清理本轮生成的测试项目、临时调试文件、截图、导出样本及旧发布目录；保留源码回归用例、固定夹具、最终审计记录和真实工作项目。实际删除成功或被文件占用的情况，以最终审计为准。

# 离线 0.7.1：工作区交互整理

本增量按用户要求重新整理 UI，保留已有领域算法、制造检查与保存协议。完整设计的未完成边界仍见 [0.7 记录](41-离线0.7大模型与颜色曲线.md)。

## 工作区结构

顶部项目栏仅负责新建、打开、保存、撤销与输出。本地项目列表归入该栏，不再悬浮覆盖其他控件。

操作阶段分为五项：模型 → 展开 → 裁片 → 花纹 → 制造。可以自由切换，不强制按顺序完成。当前阶段有明确选中状态及一句操作提示。

中央持续显示左侧 3D 与右侧二维裁版。模型参数移到右侧，预览与参数区的旧分隔条因此移除。3D 旋转、平移、缩放、正背左右视角与复位仍可用，材质颜色、透视和失真热图收入“显示”菜单。左侧裁片列表新增搜索和收起入口。

右侧只显示当前阶段的工具：

| 阶段 | 常用操作 | 按需展开 |
| --- | --- | --- |
| 模型 | OBJ/GLB 导入、物种模板 | 导入缩放、GLB 导出、自定义模板、Morph/雕刻、实验躯干 |
| 展开 | 算法、切缝、计算候选、审阅采用 | 逐片失真及求解详情 |
| 裁片 | 名称、尺寸、变换、SVG 导入 | 缝份、材料与裁剪、逐边缝份、轮廓/节点/标注编辑 |
| 花纹 | 参考图标定、分色、候选采用、3D 投影 | mask 手工修正、跨片节点与源区域编辑 |
| 制造 | 材料、接缝、排料三个子页 | 当前子页设置与报告；输出沿用已有制造阻断 |

物种参数分为身体尺寸、四肢与手足、头部与耳尾、填充与层厚；默认只展开身体尺寸。测量与拼合报告单独展开。展开候选默认显示片数、状态与最大面积/边长误差，逐片数据仍可审阅。

历史、恢复点、制造检查、计算任务统一放入中央下方可收起的“检查与记录”。生成缝份候选自动打开计算任务，避免产生结果后找不到采用入口。该抽屉与制造子页分别保存选中项。

## 状态与操作逻辑

- 切换阶段不改变项目 revision；保留本轮未提交的参考图投影参数和制造子页。
- 切换阶段或制造子页把工具滚动到顶部，标题固定；表单数据仍保留。切换项目则重新挂载项目相关参考图/制造表单，避免带入另一项目的草稿。
- 在模型/展开阶段选中裁片后进入裁片工具；在花纹/制造阶段选择裁片则留在当前阶段，便于投影花纹或关联材料。
- 离开展开阶段退出区域选面，避免隐藏的选面模式阻止模型旋转。
- 花纹投影尚无展开绑定时显示原因及“前往展开”入口；模型空状态提供创建/导入入口。
- 尺寸显示取 3 位小数，保存值与几何精度不因显示而修改。
- 保留键盘焦点样式，支持系统减少动画设置。使用本机字体和现有依赖，不需要网络字体。

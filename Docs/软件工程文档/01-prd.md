# 产品需求：五个独立页面

## 需求依据

本轮仅依据用户最新描述及图片三、图片四。上方功能顺序固定为花纹提取、模型管理、花纹映射、开裁、制版。不能因复用组件而把不属于本页的模型预览、导入工具或裁剪工具展示到其他页面。

## 页面与流程

1. 花纹提取：上传正背两张图或合并双视图，自动拆分；左侧默认简单模式、独立正背原图及部位对照，高级毫米标定和手动 mask 修正收起，右侧按身体部位及正背来源分类花纹，可修改名称、分类、颜色和路径。没有 3D 模型预览。
2. 模型管理：使用内置模型或导入 OBJ/GLB。上传后保存到模型库，支持查询、命名、删除和启用；提供参数、身体尺寸、自定义模板和网格调整，显示 3D 模型。
3. 花纹映射：显示同一项目的 3D 模型，使用共享花纹抽屉贴附；支持缩放抽屉花纹、原纹理 UV、三维手绘、补全审核、跨片路径调整、锁定和删除。模型导入不重复出现在这里。
4. 开裁：提供图片中的部件选择、曲面钢笔、自由绘制、截面环线、对称、继续绘制、切分点、中线、半侧设置和裁剪线管理。左侧 3D 与右侧 2D 裁片候选同时显示，确认颜色与失真后接受候选进入制版；计算候选不直接替换已确认裁片。
5. 制版：只有二维裁片预览，右侧选择单片或全选；调整轮廓、节点、标签、缝份、剪口和布局。A3/A4 纸张背景按毫米重复铺满，可进行单片或批量打印、分页拼接预览、裁片 ZIP 往返。材料、接缝、排料、制作流程作为本页的次级功能页，制作流程使用 JSON 保存和导入，并能返回各节点所属的主页面修改。

## 共用要求

所有左右区域使用一个可拖动分隔组件，支持方向键微调、双击恢复及保存各页比例。3D 查看器和二维编辑器均仅保留一个实现与实例，在需要的页面挂载；切换页面保留相机、预览和输入草稿。页面文件只组合对应功能模块，共享功能不得复制到每个页中。

内部几何坐标、路径、切分点和纸张尺寸统一使用 mm。人体测量可以显示 cm，同时明确毫米换算；视图缩放是显示倍率，不改变几何或打印尺度。超出一页的裁片按原尺寸分区域输出，保留重叠、页号、对齐标记和校验尺。

## 验收

- 五个标签的顺序及内容准确，花纹提取与制版没有可见 3D 模型。
- 模型管理、花纹映射、开裁共用同一预览；开裁双预览可调整宽度。
- 从上传双视图、模型保存、贴附、裁剪候选到二维调整、ZIP、JSON、打印链路可完成。
- 1440 × 960 与 1000 × 680 窗口无页面横向溢出；功能面板可滚动访问。
- 跨页快捷键不触发其他页面的编辑命令，节点编辑返回正确页面。
- 自动测试报告如实区分软件比例验证、打印接口验证与实物试印。

## 简单模式与部位匹配补充

默认一键提取应合并同色明暗、过滤细描边和平滑轮廓，参数提供简明解释。双视图用于观察正背花纹和交界，不能将不同姿势透明叠加作为三维形状。合图优先找两个人物之间的空隙。花纹建议按头、身体、脚、手爪等分类，并可修正自身左右侧。局部模型仅接收对应部位花纹；自动位置须检查确认，缺失部位和不合格投影不得强行填入。具体模块、限制和证据见 [第 48 章](48-简单花纹与部位自动贴附.md)。

## 本次工程选择与偏离（CR-001，待正式评审）

这是为可运行开发预览作出的明确限定，不是取消后续需求或降低原验收阈值。

- 数据库驱动选用 Node 内置 `node:sqlite`，Main 单写，SQLite WAL + synchronous FULL；Node 22 中该 API 有实验性标记。没有另一个 Rust 数据库写入者。
- 初版项目 schema 为无孔直线多边形子集，Piece 内联稳定节点。尚未将完整 Path/Segment/Edge 聚合及独立材料实体落地，不能声称已经实现 05 的全部表结构。所有输入严格验证；不支持的模块内容直接拒绝，避免静默丢弃。
- `.fpcad` 使用 formatVersion=1/schemaVersion=1 的开发态多边形快照；包含全部11个固定 JSON 文件，未启用模块为空。导入还未支持资源附件、外链、旧版本迁移、未知扩展保留和携带命令历史。未来正式 schema 需另行版本迁移。
- 增加 `session.read`、`session.activate`、`recovery.restore`，原生文件选择在命名方法内部完成，不向 Renderer 暴露路径。`command.apply` 首批严格 union 为 piece.put / piece.delete / project.rename；尚未实现 33 中完整 Command API。
- Rust Point/Piece 从 Zod 单源生成；数学检查仍由 Rust 执行。Node worker supervisor 使用每请求独立进程、10秒预算和8MiB输出限额。尚未实现 job.submit/result.accept 的长任务状态机和界面取消面板。
- 几何为 f64 毫米；非零 offset 限凸多边形尖角连接，miter 长度限制20倍缝份。凹形非零缝份、孔、round/bevel、逐边/可变缝份、Bézier、Boolean 均未完成。不支持的计算返回明确诊断，禁止假成功。
- 小片 warning 当前检查面积和包围框窄度，**尚未完成真实最小局部宽度及全部工艺检查**；仅能称当前实现检查未发现错误。
- 项目导入设64MiB、32条目的开发预览资源上限，低于19的目标大项目范围；超限拒绝，不静默截断。ZIP在内存中解析，拒绝符号链接，永不把包内容当磁盘提取路径执行。
- PDF 使用片号与ASCII基础标注，完整中文名称/材料作为JSON附件；SVG保留中文和毛向。PDF缺完整双语标签/毛向等制造标注，不算TC-022完整通过；PNG、大幅格式和独立打印试做未完成。
- 便携目录为内部构建方式，尚未接入 electron-builder、签名安装器、自动更新及全平台发行。运行时随包携带 Electron 和 Rust worker。
- 应用默认无网络请求、无遥测、无账号；尚未实现独立同意配置与诊断导出，因此 REQ-032 仍为部分实现。

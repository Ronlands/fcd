# 原图色区与钢笔选区重构

日期：2026-10-08。此文替代第 52 篇中关于简单／高级模式与双视图预览的说明。

## 修复内容

- 自动拆分按上传原图像素运行，不再用 512 像素代理图提取主花纹。先确定连续颜色区域，再投票生成可修改的部位标签；部位分界不再作为裁切线。
- 同一毛色的明暗合并；相邻色区还检查局部渐变连续性和整体色度。低色度 JPEG 碎点借用邻近颜色，细长色块按整体面积保留。原图测试夹具得到 71 个区域。
- 轮廓简化约束在原始像素尺度内，并检查孔洞、相交和面积偏差；不能安全平滑时保留折线。取消解剖分区造成的大段直角切口不等于消除原图本身的所有像素台阶。
- 合图原始像素随项目保存，正背在一个缩放画布中预览。轮廓只有描边，不覆盖原图颜色。内部保留视图范围和标定坐标，以支持映射与对应色区选择。
- 合并简单／高级提取入口；在花纹提取之前增加“使用指南”，集中说明流程和参数。
- 钢笔从空路径开始。单击建立节点、拖动建立曲线手柄，闭合后节点和手柄仍可调整。套索松开后保留节点。增加与减去路径支持多区域和孔洞，支持撤销、重做、载入候选和已保存路径。
- 绘制只更新向量路径。点击“确认选区并计算 mask”后，独立 worker 按原图尺寸计算；主进程的轮廓计算也移到 worker。取消或失败保持项目原状。
- 正背色区补全按颜色与部位排序候选，以镜像、主方向和毫米尺度做初始刚性对齐。可调整角度、偏移和节点，核对推断后才允许提交。

## 必须明确的边界

补全是可编辑的几何推断，不是已经恢复了真实隐藏表面。两个不同姿态的二维视图不能唯一确定三维形状；目前不自动识别遮挡边界，也不自动重建尾巴隐藏侧面。用户需选择对应区域并修正草稿，随后进行标定、模型映射和展开。

旧的 RGB 种子／Lab／HSV 局部辅助提取仍使用 512 像素代理图，界面说明会提示实际采样尺寸；主要自动色区拆分和钢笔 mask 已使用原始分辨率。低色度碎点归并可能影响小装饰，需对照原图审阅。固定毛色族也不能保证任意配色均分割准确。

草稿路径尚未随项目持久化；确认并接受的 mask、轮廓和来源会保存。图像最多 16,777,216 像素；选区最多 100 条路径、10,000 个节点，曲线展开有独立预算。超限、空选区、未闭合、无效坐标、过期来源和无效几何均拒绝提交。

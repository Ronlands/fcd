## 已修复

- 高级自动提取此前直接输出像素折线。圆形回归原有 108 个阶梯节点；现在执行轮廓简化和曲线拟合。通过拓扑检查后采用结果，若自交、孔洞交叉、孔洞丢失、方向翻转或面积偏差过大，则降级到有效折线或保留原轮廓。最终仍经过 Rust 制造几何校验。

关闭旧窗口后双击根目录 `启动新版FurryCAD.cmd`，或进入 `workflow-update` 执行 `npm start`。这两个入口使用同一个 `.local/workspace`。根目录旧 `package.json` 拒绝写入，根目录直接 `npm start` 仍是历史版本，应使用上述新版入口。已有运行窗口不会自动加载新构建。

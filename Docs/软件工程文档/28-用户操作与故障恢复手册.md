# 操作与恢复手册

## 启动本轮版本

在仓库根目录双击 `启动新版FurryCAD.cmd`，它读取根目录 `release/latest.json` 启动最新发布包。也可以在根目录执行 `npm start` 运行已构建的源码应用。当前导航顺序为使用指南、花纹提取、模型管理、花纹映射、裁切版型、拼接预览、制版，环境准备和构建步骤见 [项目 README](../../README.md)。

## 操作流程

1. 新建项目，在花纹提取选择双视图正背顺序、完整角色或局部图、实际高度 mm，点击简单模式的一键上传拆分。右侧花纹库按身体部位及正背来源分组；需要时使用两点实物标定及手动 mask 校正后重新计算。
2. 打开模型管理，点击空预览中央“创建 / 导入模型”。选择“导入 OBJ / GLB 文件”会打开本机文件选择；选择“使用内置物种模板”会展开并聚焦右侧原有物种设置，再点击生成。OBJ 坐标为 mm 时比例填 1，为 cm 时填 10；GLB 自动从米换为 mm，通常保持 1。成功后显示模型并自动保存到模型库，可改名、搜索、删除和切换；取消不会创建模型，导入错误会在选择窗口内显示。确认模型实际包含的部位；单只手爪或脚指定自身左右侧。调整参数、网格后查看实际测量尺寸。
3. 打开花纹映射，从左侧共享花纹抽屉选择来源，或在简单贴附面板按部位自动匹配。缺失部位和不合格位置会跳过并说明；旋转检查正面、背面及交界，再确认自动位置。可直接三维绘制，也可修改跨片 UV 路径；缺失区域可生成补全并在审阅后确认。花纹锁定后不能删除或随意改写。
4. 打开开裁，设置绘制部件、曲面钢笔或自由绘制、对称、截面环线、中线和半侧范围；编辑切分线或新增切分点。拖动 3D/2D 中间的竖线调整预览宽度。计算展开候选，检查颜色、轮廓和失真后接受，进入制版。
5. 在制版的裁片编辑标签选择单片，左侧预览和编辑二维节点，右侧调整名称、标签、缝份及剪口。选择 A4 或 A3 背景，单片或全选打印。超大裁片进入分页预览后按行列页号及重叠标记拼接，不缩小裁片去适应一页。
6. 导出裁片 ZIP 可再次导入继续编辑。制版中的材料、接缝和排料标签用于制造准备；制作流程标签可查看节点、编辑说明、跳转修改原始内容，并导出或导入完整 JSON 制作流。

## 预览与打印比例

花纹提取的正背图、高级标定、叠加与手工 mask 均可独立局部放大：滚轮以鼠标位置为中心，空格或中键拖动平移，“适合窗口”恢复。花纹来源、纹理、排料和打印预览使用同一查看模块；显示缩放不修改毫米尺寸。手工 mask 默认是套索，左键圈画松开自动闭合选区，增加/减去可组合选区，Escape 取消未完成路径。选区内部着色后点击计算候选。画笔加画/擦除用于细修，半径按处理像素计算。详情见 [算法与局部缩放](49-算法复核与局部缩放.md)。

如果旧项目仍显示细条或背景碎片，在简单模式点击“按当前标定重新拆分”并核对，再重新贴附；已保存来源不会自动覆盖，依赖旧拆分的贴附需要重新计算。

显示缩放不改变实物大小。输出尺寸统一以 mm 表达，100 mm 校验线可用于实物核对。打印对话框选择实际大小或 100%，按所选 A4/A3 纸张打印；硬件页边距可能要求调整后重印。软件测试覆盖纸张物理尺寸、分页、重叠、颜色和打印调用，但没有代替真实打印机与材料试做。

## 分隔条与恢复

拖动分隔条修改宽度，方向键微调，Shift 加方向键更大幅度调整，双击或 Home 恢复默认。每个页面比例自动记住，不修改裁片尺寸。

保存使用 Ctrl+S，撤销使用 Ctrl+Z，重做使用 Ctrl+Shift+Z。检查与记录面板包含制造检查、计算任务、命令历史和恢复点。导出被拒绝时按具体错误定位节点；失效绑定或未审核推断不能通过切换页面绕过。

本地会话损坏时，启动页提示已保留原记录。可通过本地项目列表选择其他正常项目继续工作；损坏记录及已有恢复点不会被自动删除。切换失败不会替换正在编辑的正常项目。磁盘写入失败或取消保存不会把项目标记为已保存。

拖动节点时若助手或其他操作已修改同一项目，旧拖动取消，按提示重新调整；切换页面也会取消未提交的拖动。忙碌期间项目切换按钮不可用，避免把结果提交到错误项目。

修改接缝、边界或剪口后，若提示配对剪口失效，应重新生成配对剪口并复核两侧位置。解除接缝会移除它生成的剪口，手工剪口保留。单片打印也会检查其配对裁片，避免拼缝定位错误。

制造输出与排料每次最多 2000 个裁剪实例、1000000 个展开坐标，分页打印最多 200 页。超过限制时减少所选裁片或裁剪数量；软件不会通过缩小尺寸或遗漏副本来绕过限制。相关问题和复验见 [全部功能与异常操作核查](47-全部功能与异常操作核查.md)。

简单模式、参数解释、原图识别与部位自动贴附的当前实现及限制见 [第 48 章](48-简单花纹与部位自动贴附.md)。

## 工作室界面与可读性

冷色面板与深蓝导航区分工作区域，黄色按钮提示主要动作，奶油色和橙色边界提示选中状态。键盘焦点仍有轮廓；系统启用减少动态效果后关闭装饰反馈。主题不改变作品颜色、毫米标定或打印比例。配色与验证说明见 [第 50 章](50-兽装工作室界面主题.md)。

## 接缝、锁定与重新开裁

保存模型现在同时保存内部接缝和配对剪口。修改锁定接缝前先解锁；模型与独立裁片有接缝时，先解除相关关联再切换模型。重新开裁会替换旧裁片，请先解除相关接缝并解锁受影响的花纹。旧花纹或推断过期时，请删除旧来源及其推断，再重新贴附和审核。导入的失效接缝也可以先解锁、再解除关联后重新配对。详细行为及本轮验证见 [第 51 章](51-全流程复验与跨步骤操作保护.md)。

二维裁片窗口的滚轮也围绕鼠标位置放大；拖动期间停止缩放，避免改变当前手势的坐标关系。取消计算后可直接重新操作，不提交被取消的候选。

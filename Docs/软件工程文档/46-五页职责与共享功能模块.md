# 五页职责与共享功能模块规范

更新日期：2026-10-07。此规范来自用户最新页面要求和参考图片三、图片四；替代此前文档中冲突的页面顺序、页面名称及预览位置。

主导航唯一顺序：**1 花纹提取 / 2 模型管理 / 3 花纹映射 / 4 开裁 / 5 制版**。

| 页面 | 主要功能 | 允许的主预览 |
| --- | --- | --- |
| 花纹提取 | 双视图上传、自动拆分、mm 标定、mask、花纹分类及源路径编辑 | 参考图片及二维来源花纹 |
| 模型管理 | 内置/导入模型、保存、查询、增删改、尺寸和网格调整 | 3D |
| 花纹映射 | 共享可缩放抽屉、贴附、原 UV、三维手绘、补全审核、花纹记录及跨片路径调整 | 3D；路径编辑模块的局部二维视图 |
| 开裁 | 曲面钢笔、自由绘制、截面、对称、继续绘制、中线/半侧设置、切分点、切分线、展开审阅 | 左 3D / 右 2D 候选 |
| 制版 | 二维微调、标签、缝份、剪口、单片/批量打印、纸张背景、裁片 ZIP、材料/接缝/排料/JSON 制作流 | 2D；无 3D |

左右区域通过同一 `WorkspaceSplit.vue` 手动调整，页面分别保存比例。开裁双预览与工具栏可以各自调整；二维纸张网格及预览缩放不改变制造比例。

每一项最终使用能力归入对应功能模块，主页面只组装模块和转发事件。模型导入与参数操作在 `ModelTools`，模型 CRUD 在 `ModelLibrary`；花纹抽屉复用 `MarkingLibrary`，既有区域贴附复用 `LegacyProjection`；纹理、推断、花纹记录和 UV 编辑分别由 `TexturePanel`、`InferenceTools`、`MarkingRecords`、`MarkingEditor` 实现；裁剪管理与展开由 `SurfaceCutPanel`、`CutLinesPanel`、`UnwrapTools`、`PreviewPiecePicker` 实现；二维状态统一在 `usePatternEditor`，视图在 `PatternCanvas`，属性与标签等已有模块组合；打印和 ZIP 由 `CutSelection` 调用统一服务，JSON 节点由 `WorkflowPage` 调用统一服务。

`App.vue` 挂载唯一模型预览和唯一二维画布，再迁移到当前页容器，避免复制业务与相机状态。页面本地输入保留，项目变化时通过项目键重置，不把临时工具状态串到另一个项目。

空模型入口通过 `ModelSourceDialog.vue` 提供来源选择，并转发到同一 `ModelTools.vue` 导入或模板设置。模型管理当前页点击同样打开选择窗口，映射和开裁首次进入则等待模型页挂载后再打开；不能只执行切页。取消不生成模型，导入成功后自动关闭窗口并显示保存的模型。入口实际可用性由 `tests/model-entry-e2e.mjs` 验证。

制版的材料、接缝、排料、制作流程是次级标签。制作流仍覆盖全部阶段，其节点能跳转到正确主页面或次级标签，并通过 JSON 导出/导入编辑。数据库字段和旧命令的内部名称不决定主导航名称。

验收入口：`tests/page-layout-e2e.mjs`、`tests/workflow-pages-e2e.mjs` 和桌面测试汇总。打印测试验证 1 unit = 1 mm、A3/A4、跨页重叠、定位标记、校验尺和原生打印调用；实际打印机缩放与材料成品需按实物验证。

## 简单模式及部位自动贴附后续修订

新增参数帮助、独立正背对照、可修正部位分类、局部模型匹配与自动位置审阅。详细共享模块和最新原图验证见 [第 48 章](48-简单花纹与部位自动贴附.md)。本章此前统计为当时验收，后续最终构建统计以第 48 章链接的最新报告为准。

图像和二维工作区的局部相机统一由 `ZoomViewport.vue` 与 `packages/ui/viewport.ts` 提供；背景连通清理由简单及高级提取共用 `packages/reference/background.ts`。手工套索在 `MaskEditor.vue` 组合已有 mask 算法，不复制提取/制造业务。最新要求、用法和验证见 [第 49 章](49-算法复核与局部缩放.md)。

全局色彩与交互反馈由共享主题提供，爪印与画布色彩分别使用单份组件和主题适配器。配色及验证边界见 [第 50 章](50-兽装工作室界面主题.md)，页面职责与制造尺寸保持本章规范。

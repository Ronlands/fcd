# 模型、映射、裁切与助手管理

本轮实现已集成至当前维护目录。最终发布标识、测试结果与清理记录见 `63-final-audit.json`；该文件生成前不能视为发布验收完成。

## 使用变化

- 花纹库与详情之间可拖动分隔条；详情中的编辑画布可调整高度，宽度与比例保存在本机。原有工作区分隔条和展开编辑继续可用。
- 提取分区使用亮度加权的八邻域路径传播，减少同色肉垫之间错误的直角边界；原图钢笔、画笔和节点编辑仍是修正歧义的入口。
- 六种内置物种重新建模，包含肩颈、下垂手臂、腿部填充、圆润足套和弯曲尾巴。生成时合并为连续曲面。已有项目的旧模型不会静默替换；重新生成模型使用新模板。
- 源花纹拖动显示拖拽预览且保留抓取点，不打开编辑详情。已贴花纹首次按下即可拖动，曲面法线变化时保持切向方向。自动匹配按部位组等比变换，并处理肢体方向；分类修改同步刷新关联花纹的配准。
- 用户绘制裁剪线后，点击“裁切并计算版型候选”，审阅二维结果与组合预览，再确认保存到裁切库。裁切库保存独立版本，可重新载入、删除或导出；仍被模型引用的记录会阻止删除。自动贴附及推断花纹必须先完成人工审核才能接受裁切，旧的未审核归档仅在模型与花纹几何和原记录完全一致时允许补做审核。
- 制版从裁切库取得版型，保留排料、缝份、剪口和打印导出。旧版独立裁片项目仍能打开和编辑。
- “AI 助手”打开管理页，包含提供商、模型、Skills、MCP 与软件连接。默认提供 DeepSeek、Ollama、LM Studio、llama.cpp、vLLM。API 密钥使用系统安全存储加密，保存/导出项目不携带密钥。
- 首页项目删除功能保留，必须由用户选择并确认。此次程序与测试产物清理不删除任何用户项目。

## 验证范围与限制

单元与集成回归覆盖模型生成/合并/拟合、花纹配准、裁切历史、缩放、资源持久化、密钥存储、模型发现及 MCP 异常会话清理。桌面回归使用隔离数据与隐藏窗口；生产程序不改变沙箱配置。受限主机的桌面测试启用测试专用 `--no-sandbox`。

自动提取及分类依据图像与部位信息，仍不能保证任意角色图的语义识别完全正确。自动映射保留审核步骤；原图遮挡或类别不明确的区域需要修正。组合预览显示裁片在原模型上的几何组合，并非布料或缝合物理模拟。模型围度按躯干解剖截面计算，排除附肢；没有实体服装试做验证。

助手页管理连接与配置，不下载模型、启动推理服务器或自动执行技能命令。MCP 支持 Streamable HTTP，连接测试仅读取工具清单。云提供商未使用真实 API 密钥验证；模型与 MCP 协议测试使用本地模拟服务。

Rust 测试可运行；本机 `cargo fmt` 与 Clippy 因路径访问拒绝而未完成，不能计为通过。Git 元数据在当前环境只读，本轮集成不包含 Git 提交或分支合并。

# 原图工作区与交互验收

本次按最新反馈重做标定、钢笔与花纹管理交互。构建及测试结果以同目录 `58-final-audit.json` 为准。

## 已实现

- 启动先展示已有项目列表，明确选择后进入编辑；项目内容仍按原有机制保存。
- 标定、颜色选取、钢笔、套索、已有花纹轮廓使用同一张原图画布。联合图保留原始尺寸和左右图的像素偏移；独立导入图在同一个工作区排列。
- 所有二维视口、裁片编辑器、模型预览默认手形平移。编辑、节点选择、模型旋转有明确工具入口，绘制期间锁定相机。
- 钢笔与套索保留可调整节点，只在确认后计算 mask。简单模式保留常用操作，高级模式展开孔洞减选、来源路径、曲线拟合和跨视图补全。
- 卡片快捷删除、复选、多选、全选、键盘 Delete；批量删除一次提交、一次撤销恢复。存在锁定依赖时整批拒绝。
- 原图按颜色选取使用原始分辨率，不再经过 512 像素代理。非法种子、标定距离、拟合容差受到校验。
- 重新标定将花纹从旧毫米坐标换算到新坐标，保持原图像素边界不动；受影响的旧贴附被移除，锁定贴附阻止操作。已删除花纹不再留下“已接受候选”的残影。
- 教程同步更新，删除不再引用的旧双视图预览组件。

## 验证范围与限制

真实图片桌面验证包括原图左右坐标、节点拖动、标定、确认计算、选区孔洞、多选删除、撤销、重启项目选择；另覆盖模板、模型拾取、映射、开裁、制造、打印、资源导入导出、保存恢复、取消与异常操作。每组结果及所测发布包记录在审计 JSON 中。

本轮执行的是列明的针对性桌面套件，不把未重跑的历史测试算作通过。历史测试中依赖已移除的独立标定画布、Lab/HSV 参数面板等步骤仍需迁移；完整 `test:desktop` 默认清单不等同于本轮验证清单。

旧项目花纹不会自动重新分割；隐藏区域仍需审阅，不能保证从正背图唯一恢复真实裁切形状。合图中的两个参考区域共享显示画布，但一个选区草稿仍归属一个参考区域；存在草稿时切换绘制区域会提示先确认或清空。兼容接口中的 Lab/HSV 聚类保留原有代理处理。

受限测试环境使用 `FPCAD_TEST_NO_SANDBOX=1`；生产程序保持沙箱配置。此包仍为离线开发预览，测试通过不代表已经完成商业发布认证。

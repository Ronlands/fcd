# 兽装工作室界面主题

更新日期：2026-10-07。配色来自用户提供的两张色卡，五个业务页面、共享控件、弹窗、花纹抽屉、制作流和预览工具共同使用这一主题。

## 色卡与分工

| 色彩 | 原始值 | 界面用途 |
| --- | --- | --- |
| 深海青 | #022b3a | 顶栏、状态栏、画布工具条和爪印标识 |
| 青蓝 | #1f7a8c | 品牌细节、交互提示；正文使用更深的同色系衍生色保证可读性 |
| 浅天蓝 | #bfdbf7 | 页面层级、阶段编号、淡蓝面板的基础色 |
| 淡紫灰 | #e1e5f2 | 模型阶段编号及柔和的冷色层次 |
| 白色 | #ffffff | 内容面板、输入框、打印纸张 |
| 海军蓝 | #0d3b66 | 工作流导航、标题和阴影基色 |
| 奶油色 | #faf0ca | 选中控件和下一步提示 |
| 明黄色 | #f4d35e | 主要操作、品牌标识、键盘焦点反馈 |
| 橙色 | #ee964b | 阶段编号、选中边界、局部装饰 |
| 珊瑚红 | #f95738 | 制版阶段及错误提示的色系；错误正文采用更深衍生色 |

冷色承担工作台与内容层级，暖色强调创作动作。软圆角、爪印、轻微按压和悬停反馈增加亲和感；图像和几何画布保持安静。操作反馈时长为 180 ms，系统启用“减少动态效果”时禁用装饰动画和过渡。

## 单份模块

- `apps/desktop/src/tokens.css`：两张色卡、背景、文字、边框、状态和运动参数。
- `apps/desktop/src/studio.css`：全局工作室样式，最后导入；页面沿用既有布局和事件。
- `apps/desktop/src/StudioMark.vue`：共享爪印品牌组件。
- `apps/desktop/src/modules/canvasTheme.ts`：3D 画布背景、网格与阴影从主题读取。
- `apps/desktop/src/WorkspaceSplit.vue`：同一拖动/键盘分栏控件，新主题增强分隔条可见性。

既有组件中的固定深绿界面色改用语义变量。初次迁移覆盖 30 个样式文件的 216 条声明，随后针对弹窗、画布和选中状态进行逐项检查。未新增样式框架、运行时依赖或在线字体。

## 作品与制造边界

主题只改变界面与辅助显示。花纹库颜色、模型花纹贴附、裁片填色和导出文件沿用项目中的原始颜色。物理尺寸、毫米标定、缝份、裁剪比例、A3/A4 分页与打印参数不因主题改变。失真诊断仍保留绿→黄→红的含义；模型部位的区分配色和新建花纹默认颜色属于业务显示或项目数据，未用主题覆盖。分页拼接图上的页框是界面辅助标记，不写入打印产物。路径点、标定线、贴附轮廓和 3D 标签使用共享主题，3D 标签带浅色描边以提高复杂底色上的可读性。

当前模型来源窗口仍调用共享导入和模板模块；缩放、分栏、单片预览和流程节点继续调用已有业务模块，不复制实现。

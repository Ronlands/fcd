# 系统架构

## 当前界面边界

Electron 渲染端组成五页：花纹提取、模型管理、花纹映射、开裁、制版。`App.vue` 负责项目壳、导航、全局命令与模块挂载；几何与持久化服务不属于任何单页，所有页面访问同一项目。

`useSession` 保存服务返回的项目、修订号、历史、恢复点和计算状态。每次写命令携带项目 ID 和预期修订号，成功后刷新统一状态；切换标签只影响展示，不产生项目修订。

## 几何与资源链路

双视图资源 → mm 标定及拆分 → 分类花纹库 → 当前模型与独立模型库 → 三维贴附记录 → 裁剪线和切分点 → 展开候选及对应关系 → 已确认二维裁片 → 标签、缝份、材料、接缝、排料 → 打印与交换。

来源花纹、三维重心坐标片段和二维 UV 路径保留关联。插入切分点及重新展开须保留有效贴附颜色；无法逆映射或已失效绑定不得静默保存。待审核的推断花纹在修改后重新失去制造确认资格。

耗时几何计算通过工作器执行。候选与最终数据分开，审阅接受后才写入最终裁片，并可撤销。已有工作器、IPC、模型库、资源存储、ZIP、JSON 和打印服务由新页面直接复用。

## 前端共享实例

一个 `ModelViewport` 包装唯一 `SurfacePanel`，通过 Teleport 移到模型管理、花纹映射或开裁的容器。其他页面把实例放入隐藏停放容器，不创建第二个模型窗口。

一个 `PatternCanvas` 使用 `usePatternEditor` 的统一状态和命令，在开裁显示候选，在制版显示最终二维裁片；注入键 `patternEditorKey` 供属性模块共享相同的选择、工具、视图与纸张设置。

`WorkspaceSplit` 是全部分隔条的唯一实现。布局比例属于本地界面设置，保存在 `localStorage`，不混入毫米几何或制作流格式。

## 制作流与本机助手

制作流在制版次级标签中展示整个项目节点，JSON 可携带当前项目并往返加载，节点编辑跳转正确主页面或制版次级标签。本机助手沿用受控回环接口和连接开关，通过同一命令及修订检查修改项目，不绕过业务校验。

# 软件工程文档使用指南

目录说明更新日期：2026-10-12。当前应用直接在仓库根目录维护，根目录 `启动新版FurryCAD.cmd` 根据 `release/latest.json` 启动最新版。源码运行、安装依赖和构建命令也都在仓库根目录执行，详见 [项目 README](../../README.md)。历史验收记录中的旧嵌套目录路径保留为当时环境的记录。
